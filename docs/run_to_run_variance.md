# 同种子重跑方差：`--seed` 在 20000 步尺度上控制不住这个世界

**这份文档不是一个生态结论，是一把尺子。** 它测的是「**同一个种子、同一份配置、同一份代码**
再跑一遍，结果会差多少」——而本项目所有实验的统计协议（6 配对种子起、配对 Wilcoxon、
逐种子护栏）都默认这个量小到可以忽略。测下来它不小。

发现于 2026-08-03 的 R3 判决（`multispecies_program.md §11.5`）：
判据的容差宽度约等于一个复现噪声 SD，于是「通过/不通过」都不携带信息。

---

## 1. 已知的前情：`conventions.md §9` 说的是 200 步

现有约定写的是：

> 按格子的 scatter-add 是原子操作且会重排……不过实测：在 smoke 配置
> （2048 agents、**200 步**）上连跑五次，全部十个指标漂移 **0.000%**——重排在这个规模下
> 没有显现。

**这句话没错，但它只覆盖 200 步。** 本项目所有生态判决跑的是 **20000 步**，
中间隔着 100 倍的时间让任何一次浮点重排放大。混沌系统里这是意料之中的，
但它从来没有被测过，于是「6 配对种子」这个统计地板一直建立在一个未经检验的前提上。

### 4.3 确定性 XLA 算子：能修，但对 20000 步不实用

`XLA_FLAGS=--xla_gpu_deterministic_ops=true` 的 6 个 run 跑了 **57 分钟仍未完成**
（CPU 时间 53 分钟、GPU util 100%，确认在算而非回落 CPU），而同配置普通 run 只要 **4.5 分钟**——
**慢一个数量级以上**。合理解释：本世界每步做多次 `[n_cells]` 的 per-cell scatter-add
（`graze` / `eat_fruit` / `trample` / `fear` / `carrion`），确定性 scatter 要放弃原子加、
改用排序或串行归约，代价极高。

为腾出槽位给 `s3_norm`，杀掉其中 3 个、保留 3 个（**判断「确定性是否真的消除散度」只需 2–3 个
——若有效，它们的结果会完全相同**）。
**[本世界实测] 判决：确定性算子不是本项目可用的解药**，20000 步 × 6 配对种子 × 多臂的
预算下它把一次 sweep 从 15 分钟变成数小时。剩余 3 个 run 的结果见 §4.4。

### 4.4 确定性臂最终被放弃（**「它能否消除散度」仍未测**）

保留的 3 个 `s0_det` 跑到 **100 分钟仍未完成**（普通 run 4.5 分钟，即 **>20× 慢**），
最终因为堵塞后续实验被杀掉。

**[本世界实测] 所以本文档只证明了「确定性 XLA 算子在这个规模上不可用」，
没有证明「它能消除散度」——后者未测，别把它写成已知。**
但对决策而言这不重要：一个跑不完的模式，能不能修都是空谈。

**[提案，非结论]** 若将来要验证这条因果（散度是否确实来自原子 scatter-add 重排），
成本更低的做法是**在小配置上跑**（`tiny_cfg` 级、2000 步），那里确定性算子的代价可以接受；
或者只对 `dynamics.graze` 的单个 scatter-add 做微基准，不必跑整个世界。

## 5. 对统计协议的影响

**先写下推理框架，数字回来只填数字**：

配对设计的方差分解。一次 run 的结果 `Y = μ + F(seed) + C(chaos)`，其中 `F` 是创始者效应、
`C` 是混沌/重排实现。
- **跨种子 SD** 测的是 `√(σ_F² + σ_C²)`。
- **同种子重跑 SD** 测的是 `σ_C` 单独。
- **配对**（同 seed 跑两臂）消掉的只有 `F`，**留下的是两个独立的 `C`**，
  所以配对差的 SD 是 `√2 · σ_C`。

于是：**配对买到的好处只在 `σ_F` 占总方差的份额上。** 若 `σ_C ≫ σ_F`（先导数据指向这个方向），
配对几乎没有减噪，而「6 配对种子」的功效计算（`conventions.md §5`）用的是跨种子 SD——
那个数**低估**了配对差的噪声（低估倍数是 `√2·σ_C / √(σ_F²+σ_C²)`，当 `σ_F→0` 时趋近 `√2`，
当 `σ_C ≫ σ_F` 时就是 √2，即功效算术里的 SD 至少要乘 1.41）。

**可用的对策（按代价排序）**：
1. **每格重复 k 次取均值**：噪声降 `√k`，代价是 run 数 ×k。k=3 时噪声降 42%。
2. **确定性 XLA 算子**：若 §4 证实有效，则 `σ_C→0`，配对恢复全部效力，代价是步进变慢。
3. **只报效应量对复现 SD 的比值**，别报「几/6 逐种子达成」——后者在容差 ≈ 1 SD 时是抛硬币。
4. **护栏的容差要显式对着复现 SD 定**，不要凭直觉写 ±10% 或 +5pp。

### 5.1 把数字代进去（这是本文档的可操作产出）

**配对差的噪声 = `√2 · SD_within`**（配对消掉创始者，留下两个独立的混沌实现）：

| 指标 | `SD_within` | **配对差噪声 √2·SD_w** | `conventions.md §5` 记的跨种子 SD | 低估倍数 |
| --- | --- | --- | --- | --- |
| `carnivore_frac` | 0.0442 | **0.0625** | ±0.012 | **5.2×** |
| `population` | 122.3 | 173.0 | （未记） | — |
| `death_thirst_frac` | 0.0464 | 0.0656 | （未记） | — |
| `forage_pref_std` | 0.0103 | 0.0146 | （未记） | — |

**[本世界实测] `conventions.md §5` 用 `carnivore_frac` 跨种子 SD ±0.012 做的功效算术，
用错了 SD——配对检验该用的是 0.0625，大 5.2 倍，于是所需样本量被低估约 27 倍。**

**配对到底买到了什么**：配对把差值方差从 `2(σ_W²+σ_B²)` 降到 `2σ_W²`，
即降低倍数 `1/(1−ICC)`。代入：
- `carnivore_frac`（ICC 0.130）→ 方差降 15%，**SD 只降 7%**。配对几乎白配。
- `late_carn` / `death_thirst_frac` / `total_flux`（ICC 0.000）→ **配对一点用都没有**。
- `forage_pref_std`（ICC 0.547）→ SD 降 33%，配对确实有用。
- `forest_frac`（ICC 0.474）→ SD 降 27%。

**结构性发现：ICC 高的是「基因/性状类」指标（`forage_pref_std` 0.547、`forest_frac` 0.474、
`carn_attack` 0.389），ICC 低的是「人口统计类」标量（`late_carn`、`death_thirst_frac`、
`carnivore_frac`）。** 前者由创始者基因池决定、演化轨迹相对可复现；后者是混沌的种群动力学。
**这意味着性状演化类结论（armor、红皇后）比种群比例类结论（`carn_frac`）站得更稳**，
不该被一竿子打翻。

### 5.2 什么**没有**被这份文档推翻

- **已发表的 Wilcoxon p 值本身没错。** 它们算的是**实测配对差**，那些差里已经包含了
  `√2·σ_W`。错的是**功效规划**（用了太小的 SD）、**护栏容差设计**（凭直觉写宽度）、
  以及「配对控制住了主要噪声」这个信念。
- **6/6 同向的符号检验仍然有效**，只是它的证据强度要按真实噪声重估：
  真效应 `d`、配对差噪声 `s` 下，单种子同向概率是 `Φ(d/s)`。
  `pred_nocturnal` 的 `carn_frac` +0.033 对 `s`=0.0625 → `Φ(0.53)=0.70` → 6/6 概率 0.118；
  零效应下 6/6（单向）概率 0.0156。**似然比约 7.5，是证据，但不是强证据。**

## 7. 新协议（**用户已拍板执行，2026-08-03**）

### 7.0 先修正我自己的建议：**加种子比加重复值钱**

我最初提的是「每格 k=3 重复」。分析 P3 时发现这个分配不是最优的，**改建议之前先把算术写出来**：

设每臂总 run 数 `N = s × r`（`s` 个种子、每格 `r` 次重复）。配对差的均值标准误是

```
SE = σ_W · √( 2 / (s · r) )
```

**只取决于乘积 `s·r`，与怎么分配无关。** 所以在同样的 GPU 预算下，`s` 和 `r` 对精度的贡献
一模一样。但两者有三点不对称：

1. **符号秩检验的 p 下限只由 `s` 决定。** `s=6` 时最小双侧 p 就是 **0.031**——
   **无论数据多干净都到不了更低**。这正是本项目结论反复卡在 0.031 的机械原因。
   `s=12` 时下限降到 0.00049，才有真正的分辨力。
2. **伪重复只由 `s` 决定。** `terrain.build` 不吃 RNG，多一个种子多一次创始者抽样；
   多一次重复什么都不多。
3. **`r` 唯一不可替代的作用：让实验自己估出自己的噪声。** `r=1` 时无法从本次实验内部
   估 `σ_W`，只能引用本文档 §4 的存档值；`r≥2` 就能就地估。

**→ 结论：`r` 取 2（够估噪声、且把每对效应量抬 √2），剩下的预算全部投给 `s`。**

### 7.1 新默认协议

| 项 | 旧 | **新** |
| --- | --- | --- |
| 种子数 `s` | 6 | **12** |
| 每格重复 `r` | 1 | **2** |
| 每臂 run 数 | 6 | **24** |
| 双侧 p 下限 | 0.031（地板，常年顶到） | **0.00049** |
| 两臂一轮 | 12 run，约 12 分钟 | **48 run，约 45 分钟** |

**分析口径**（三条，缺一不可）:
1. **先把每格 `r` 次重复取均值，再做 `s` 个格均值的配对检验。** 不得把 `s×r` 个 run
   当成 `s×r` 个独立样本——重复是同种子复跑，只含混沌噪声。
2. **必报「效应量 ÷ 配对差噪声」**，噪声 `= √2 · σ̂_W / √r`，`σ̂_W` 从本次实验的格内散度
   自估（不许引用别处的数）。**比值 <1 一律标注功效不足**，哪怕 p 过线。
3. **护栏容差必须对着 `√2·σ̂_W` 定**，不许凭直觉写 ±10% / +5pp。
   参考量级（§4）：`carnivore_frac` 的 `√2·σ_W ≈ 0.0625`、`death_thirst_frac ≈ 0.066`。

**不采用确定性 XLA 算子**（§4.3/§4.4：>20× 慢，跑不完）。
