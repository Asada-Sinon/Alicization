# 同种子重跑方差：`--seed` 在 20000 步尺度上控制不住这个世界

**这份文档不是一个生态结论，是一把尺子。** 它测的是「**同一个种子、同一份配置、同一份代码**
再跑一遍，结果会差多少」——而本项目所有实验的统计协议（6 配对种子起、配对 Wilcoxon、
逐种子护栏）都默认这个量小到可以忽略。测下来它不小。

发现于 2026-08-03 的 R3 判决（`multispecies_program.md §11.5`）：
判据的容差宽度约等于一个复现噪声 SD，于是「通过/不通过」都不携带信息。

## 1. 已知的前情：`conventions.md §9` 说的是 200 步

现有约定写的是：

> 按格子的 scatter-add 是原子操作且会重排……不过实测：在 smoke 配置
> （2048 agents、**200 步**）上连跑五次，全部十个指标漂移 **0.000%**——重排在这个规模下

**这句话没错，但它只覆盖 200 步。** 本项目所有生态判决跑的是 **20000 步**，
中间隔着 100 倍的时间让任何一次浮点重排放大。混沌系统里这是意料之中的，
但它从来没有被测过，于是「6 配对种子」这个统计地板一直建立在一个未经检验的前提上。

## 3. 这一轮测什么（先写后跑，run_id: 20260803-variance）

**这是一次测量，不是对比实验，没有哪个臂「更好」。**

| 臂 | n | 配置 | 回答什么 |
| --- | --- | --- | --- |
| `s0_norm` | 8（+ §2 的 6 = **14**） | 默认，seed 0 | 同种子散度到底多大（把 SD 估准） |
| `s0_det` | 6 | 默认，seed 0，`XLA_FLAGS=--xla_gpu_deterministic_ops=true` | **能不能修** |
| `s3_norm` | 6 | 默认，seed 3 | 散度是不是 seed 0 特有的 |

**什么结果会改变读数**（先写下来，防止事后讲故事）：

- 若 `s0_det` 的散度**塌到接近 0** → 原因确认为原子 scatter-add 重排（外加 XLA 自动调优的
  算子选择）被 20000 步混沌放大，**而且有一个（更慢的）确定性模式可用于判决 run**。
- 若 `s0_det` 散度**和 `s0_norm` 一样大** → 不确定性来自别处，那个 flag 不是解药，
  只能靠「每格重复 k 次取均值」（噪声降 `√k`）来压。
- 若 `s3_norm` 的散度远小于 `s0_norm` → 散度是种子特异的（某些创始者落在更混沌的吸引子附近），
  结论要按种子分别陈述，不能一概而论。

## 5. 对统计协议的影响

待填。**先写下推理框架，数字回来只填数字**：

配对设计的方差分解。一次 run 的结果 `Y = μ + F(seed) + C(chaos)`，其中 `F` 是创始者效应、
`C` 是混沌/重排实现。
- **跨种子 SD** 测的是 `√(σ_F² + σ_C²)`。
- **同种子重跑 SD** 测的是 `σ_C` 单独。
- **配对**（同 seed 跑两臂）消掉的只有 `F`，**留下的是两个独立的 `C`**，
  所以配对差的 SD 是 `√2 · σ_C`。

于是：**配对买到的好处只在 `σ_F` 占总方差的份额上。** 若 `σ_C ≫ σ_F`（先导数据指向这个方向），
配对几乎没有减噪，而「6 配对种子」的功效计算（`conventions.md §5`）用的是跨种子 SD——
那个数**低估**了配对差的噪声（低估倍数是 `√2·σ_C / √(σ_F²+σ_C²)`，当 `σ_F→0` 时趋近 `√2`，
当 `σ_C ≫ σ_F` 时就是 √2，即功效算术里的 SD 至少要乘 1.41）。

**可用的对策（按代价排序）**：
1. **每格重复 k 次取均值**：噪声降 `√k`，代价是 run 数 ×k。k=3 时噪声降 42%。
2. **确定性 XLA 算子**：若 §4 证实有效，则 `σ_C→0`，配对恢复全部效力，代价是步进变慢。
3. **只报效应量对复现 SD 的比值**，别报「几/6 逐种子达成」——后者在容差 ≈ 1 SD 时是抛硬币。
4. **护栏的容差要显式对着复现 SD 定**，不要凭直觉写 ±10% 或 +5pp。
