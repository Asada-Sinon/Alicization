## 1. 纲领：本世界为什么现在只有一个物种可活

把已归档的判决串起来，多物种失败不是三次独立失败，而是**同一个根因的三个投影**：

| 已判决 | 表面结论 | 投影回的根因 |
| --- | --- | --- |
| `feasibility.md §1` diet 轴中段死区（六种子全灭绝） | 第三营养级进不去 | 营养级轴上只有两个可活点 |
| `feasibility.md §9.5` forage_pref **证否**（方差反向塌缩 32.6%） | 资源分割不发生 | ~~果层只有草层的 0.07%，没有第二个饭碗可专精~~ **← 这条归因已被 §9.8 证否**：给了 28% 的真饭碗 + 最大选择强度，塌缩反而更深（−38.3%）。真因是**中间型最优**，不是没有饭碗 |
| `feasibility.md §7` 腐食 v2 18 配对翻正但带 −5.6% 种群代价、跨地形只 4/5 | 腐食通路太稀薄 | 尸体流量相对草层同样是零头 |
| `water_system.md` / `day_night.md` 「捕食者搬离河岸」结构不可达 | 空间分化不发生 | **水把所有个体钉在河岸，只有一种栖息地** |

**[本世界实测] 一句话根因：这个世界只有一个饭碗（河岸的草），所以只能坐得下一个食草生态型。**
金标 `plant_total=10790` vs `fruit_total=40.3`（`scripts/golden.json`）——果层是草层的 **0.37%**，
20000 步长跑下更低（§9.5 测得 0.07%）。在这种供给比下，任何「专精果实」的基因型都必然饿死，
方差塌缩是**正确**的演化响应，不是机制没点火。

**所以纲领是：先造出第二个生态位，再谈第二个物种。** 顺序不能反——先加基因、再指望生态位
自己出现，已经被 forage_pref 那次证否了（付了永久 `trait_dim` 7→8 的代价）。

### 1.1 三条候选轴（按「造饭碗」的便宜程度排序）

1. **资源轴——加厚果层。** 纯 `--set`（`fruit_max` / `fruit_regrow_rate` / `fruit_patch_threshold`），
   零代码、零种群作废；forage_pref 基因**已在 main**，代价已付。**这是第一回合。**
2. **空间轴——让第二个栖息地能活人。** 水是硬约束（`water_system.md`），但果层若够厚，
   林冠区（中海拔近水）本身就是一个和河岸草原不同的斑块。空间分化是「**局部**多物种」这个
   诉求的字面含义，需要新的读出指标（生态型 × 空间的联合分布），不是新机制。
3. **营养级轴——腐食 / 顶级捕食者。** 已知稀薄；腐食留作已翻正但带代价的价值决策，
   顶级捕食者只作快速证伪。**排在资源轴与空间轴之后**，因为它们不造饭碗，只分饭碗。

### 1.2 什么算「成功」（终局判据，先写后跑）

用户要的是「局部的多物种生态箱演化」+ 看得见的可视化。拆成四条可证伪的：

- **S1 生态位存在**：第二资源层的现存量 ≥ 草层的 10%（当前 0.37%），且不靠杀死草层达成。
- **S2 分化发生**：`forage_pref_std` 处理臂 > 对照臂，≥5/6 同向，配对 Wilcoxon p≤0.05；
  且基因分布的**形状检验**拒绝单峰（真·双峰，不只是方差变大）。
  **[修订 2026-08-02，跑之前改，理由在此]** 原文写的是 Hartigan dip test。本环境无
  `diptest` 包，而手工移植 AS 217 的 GCM/LCM 交替拟合是典型的「错了不报错、只返回一个
  看起来合理的数」——正是本项目反复警告的那类失效。改用**1-vs-2 高斯成分的参数自助
  似然比检验（BLRT，McLachlan 1987）**：EM 拟合、LR 统计量、自助零分布三部分都能对着
  已知真值的合成数据验，`tests/test_kernel.py::test_shape_test_separates_unimodal_from_bimodal`
  就在验。它对「性状替代=两个群」这个**具体**备择假设也比通用单峰性检验更有功效
  （dip 检验的是对任意单峰性的偏离）。实现在 `scripts/probe_trait_dist.py`。
  **[再修订，仍在跑之前] 形状检验的绝对 p 值在演化种群上无效，判据改为配对臂间比较。**
  实测（2000 步、seed 0、herb 携带者）：`forage_tradeoff=0.5` 给 LR=212.8 / p=0.0200（地板），
  而**中性对照 `forage_tradeoff=0.0`——基因被编译期断开、什么都做不了——同样给 p=0.0200 地板**。
  根因：演化种群不是随机样本而是**谱系**，亲缘共享基因值使分布天然呈家系团块，
  有效样本量是独立世系数而非个体数，自助零分布（按 iid 重采样）因此窄得离谱。
  故 S2 的形状部分改判为：**`blrt_lr_per_n` 处理臂 > 对照臂，6 配对种子 Wilcoxon**。
  除以 n 是因为 `2(ll2−ll1)` 随样本量线性增长而两臂携带者数不同，直接比 LR 等于在比种群大小。
- **S3 局部性成立**：两个生态型在空间上分开——生态型 × 栖息地（林冠/河岸）的联合分布
  显著偏离独立零模型（这条**必须跨地形种子**，否则是伪重复，见 `conventions.md` §6）。
- **S4 不塌方**：护栏三条同时守住——`carnivore_frac` ≥ 0.05（捕食者不灭绝）、
  `population` 相对基线在 ±30% 内、`death_thirst` 占比不恶化。

S1→S2→S3 是**串联**的：S1 不成立就不必跑 S2（这正是 §9.5 那次浪费掉的 36 个 run 的教训）。

## 2. 循环工作流（七道闸）

**一回合 = 一个可证伪假设走完七道闸。** 每回合结束在台账（§3）追加一行。
闸门是顺序的，前一道不绿不许进下一道；某道闸黄了就**降级本回合的 claim**，不是放宽闸门。

### G0 选题
从 §4 backlog **顶部**取一条。取出来必须当场能写成「假设 + 成功判据数字 + 失败判据」，
写不出具体数字说明还没想清楚——那就把它拆开，先跑一个能写出数字的探针回合。
按 `/exp` 第 1 步的字段，在目标 `docs/<topic>.md` **先建一节**（此时实验还没跑）。

### G1 净树
`git status --short` 干净、`check.py` 绿。不干净先提交——脏树上跑出的结果 provenance
对不上任何 commit（`MEMORY.md` 的 `[LEARN:tooling]` 就是这条）。

### G2 最小改动
**能用 `--set` 做到就绝不写代码。** 必须写代码时：默认关、旧路径 bit-exact、补单元测试、
`check.py --full` 全绿、提交（中文 message，说清为什么改）。
动 `in_dim` 要单独确认（作废全部演化脑）；动默认生态参数要预告 golden 重 bless。

### G3 跑
**12 配对种子 × 每格 2 重复** × 2 臂（`run_to_run_variance.md` §7；
⚠️ **本节原文写的是「6 配对种子」，同 §7 的更正，已改**），
**并发上限视显存而定**（`nvidia-smi` 先看——这张卡是共用的），`--json`，
产物落 `outputs/<run_id>/`，先写 `provenance.txt`（git hash + resolved config + seed 列表 + 完整命令）。
后台跑，别傻等；12 个 run 约 10–15 分钟，36 个约 27 分钟。
**空间性结论额外交叉地形因子**（`ridge_wavenumber` / `ridge_base_y`），否则是伪重复。

### G4 判决
**派 `result-analyst` 读 `outputs/`，主控不自己读日志**（十几个 run 的日志进主 context 就清不掉，
而且 fresh eyes 不知道我希望看到什么）。要求：逐种子数字 + 每个数字的出处文件 +
配对 Wilcoxon/Mann-Whitney + 效应量 + bootstrap CI + 判据逐条「达成/未达成」。
**n=6 配对的最小双侧 p 是 0.031——那是地板，不是强证据**（n=12 才降到 0.00049）。
**同理，蒙特卡洛零假设的 p 下限是 `1/(reps+1)`**，估计量必须用 `(1+k)/(reps+1)`
而不是 `(cnt>=T).mean()`（后者能取到恰好 0，那不是有效的 p 值）——
`MEMORY.md [LEARN:stats]`，本项目已被 p 地板咬过两次。

### G5 落档
结果写回 G0 建的那一节，**四标签逐条标注**（`[现实]`/`[本世界实测]`/`[对应]`/`[提案，非结论]`）。
负结果照样完整写——它们是唯一能阻止同一个想法被重试的东西。
`docs/TODO.md` 加指针；§3 台账加一行；§4 backlog 按判决重排（判决要能改变下一回合选题，
否则这个回合白跑）。提交 + push。

### G6 可视化闸
**每 3 回合，或任何机制转为默认开时，必过一次。** 本项目有过教训：着色器把植物场画成
一块饱和色板，只靠读代码审了很久没发现（`CLAUDE.md`「用眼睛验证 GPU 与画布输出」）。
过法：起 `run_live.py`、headless chromium 截图（`--use-gl=angle --use-angle=swiftshader
--enable-unsafe-swiftshader`）、**人眼看**。终局交付物是「生态箱面板」（§1.2 四条判据各一张图）。

### 停机与降级规则
- backlog 空了 → 不停机，去 §4 的「补给区」按纲领生成新候选。
- 撞到需要用户拍板的岔路（会作废种群 / 会改默认生态 / 花费超过一晚）→ **不擅自选一条**，
  写进 `HANDOFF.md` 的 PENDING，然后**跳过它继续下一条 backlog**，不要停在那里等。
- 某回合判决为负 → 这是正常产出，不是失败。落档、更新 backlog、进下一回合。

### 两条必须记下来的诚实说明

**(1) [对应] `frb=0.25` 与设计意图冲突。** 相对容量的自发再生速率：草层
`0.015/2.2 = 0.68%/步`，果层 `0.25/4.0 = 6.25%/步`——**果子比草恢复快约 9 倍**，而
`config.py:541` 写明「fruit's slowness is exactly what makes a remembered patch worth
something」。把果层做成快速再生资源，专精它就不再是一种不同的生活方式，只是换个地方吃。
r1（frb=0.10 → 2.5%/步，仍比草快 3.7×）程度轻些但同向。**这是一笔要认的账，不是可以
略过的细节。**

**(2) [对应] 面积路线有硬天花板，到不了 20%。** `terrain.py:207` 是
`fruit_capacity = fruit_max × patch × forest² × (1-rock)`——果层被**森林平方**门控。
于是 (i) 抬 `fruit_max` 对基线通量**完全无效**（通量 `= baseline_rate × Σ(cap/fruit_max)`，
`fruit_max` 约掉了），这正是探针一里 p3/p4 抬容量没反应的原因；(ii) 把
`fruit_patch_threshold` 放到底，`Σ patch·forest²` 最多涨约 10×，即通量约 3 单位/步、
份额约 1.2%。**空间独特性是 `forest²` 给的，不是斑块阈值给的**——所以放宽阈值不会把果实
漏进草原，但也救不了量级。

### 我自己预注册里的算术错了（记下来，但不用它改本轮判据）

§6 立门槛时我论证「`forage_tradeoff=0.5` 下专精者在本层拿 1.5×、另一层只剩 0.5×，
所以果层至少要供到两成，专精果实才不亏本」。**这个论证是错的**：资源分割是频率依赖的。
设果层占植物总供给 `f`、专精果实者占种群 `q`，两类专精者的人均获得在平衡时相等：
`1.5f/q = 1.5(1−f)/(1−q)`，解得 **`q = f`**。

**也就是说任何 `f` 都能撑起一个比例为 `f` 的亚种群，专精者永远不亏本。** 真正卡住分化的
不是 `f` 有多大，而是**选择梯度能否压过基因流**——那取决于 `forage_tradeoff` 的**强度**
（以及有无生殖隔离），不取决于果层份额。`§9.5` 那次证否的根因诊断（「果层只有 0.07%、
无生态位可专精」）**在这个意义上也是不完整的**：0.07% 的问题不是「专精不划算」，而是
比例为 0.0007 的亚种群会被漂变和基因流直接抹平。

**但这不构成事后改判据的理由。** 判据按原文跑完、按原文判（见 §7），算术更正只用来指导
R2：R2 必须把 `forage_tradeoff` **强度**当作与果层份额同等重要的因子，而不是只开 0.5 一档。

### 7.5 渴死破在哪：代码层面已定位，且方向与真实生态相反

**[对应]** `dynamics.graze:143` 返回水 `= gain × forage_water_frac`，而草的
`gain = biomass × eat_efficiency`（无能量系数，`eat_efficiency=1.0`）→ **草每卡路里给 0.10 水**。
`dynamics.eat_fruit:174` 返回水 `= taken × forage_water_frac`，用的是**生物量**，
而 `gain = taken × fruit_energy × eat_efficiency` → **果实每卡路里只给 `0.10 / fruit_energy` 水**。

于是 `fruit_energy=4.0` 时果实每卡路里的水只有草的 **1/4**，`fe=6.0` 时只有 1/6。
把两成热量挪到果实，就等于砍掉近两成的觅食水补贴——**渴死护栏破在这里，不是玄学**。
死因分解自洽：两臂饿死都降（−0.020/−0.018），压力转移到渴死。

**[现实] 而这与真实生态相反。** 果实含水量典型 80–90%，高于草料的 60–80%；
`graze` 自己的注释就引了「Real herbivores draw much of their intake preformed」，
`biology.md` 有「预成水」一节。**当前实现让果实比草更干，是一处与文献相反的建模选择**
（草的水挂能量、果实的水挂生物量，两处口径本就不一致）。

**→ 这直接生成 R1c（§8）：给果实它应有的预成水，再看渴死护栏是否可修。**
若可修，则 R1b 的失败是口径问题而非果层路线的本质代价；若不可修，果层路线证伪成立。

## 10. 三个回合合起来的真结论：水限世界里，加食物只会变成更多身体

R1 / R1b / R1c 是三次独立的失败，但指向同一堵墙，值得单独立一节，因为它改写纲领。

**[本世界实测]** 果层供能份额可以从 0.1% 一路做到 25%（这一点毫无疑问、6/6、p=0.031 地板）。
但每一次，多出来的能量都**转化成更多的身体，而不是另一种活法**：种群 +16~22%，
`mean_water` 不动，渴死随种群走（ρ=+0.90）。

这与两份已归档的判决是同一堵墙：
- `herbivore_overpopulation.md` §6：四条降密度杠杆全部失败，根因水限 + 密度尺度不变。
- `water_system.md`：**每一个有效水杠杆都让种群涨 27–72%**、捕食者占比升到 33–41%。

**合起来的命题（本纲领的核心修订）：在一个承载力由水锁死的世界里，
「增加食物供给」这条路造不出第二个生态位——它只会等比例地造出更多同一种生物。**
第二个生态位必须来自**不增加承载力**的轴：

- **(i) 重新分配现有生产力**：把总植物通量保持不变、只改变它在草/果两层之间的**构成**。
  这与 R1b/R1c 测的「加厚」是**不同的假设**，不是它的救援臂——加厚测的是「更多食物」，
  再分配测的是「同样多的食物，两种吃法」。→ **R3（§11）**
- **(ii) 分割空间或时间**：同一份资源、不同的取用地点或时段，零新增能量。
  → 原 backlog 的空间轴，`day_night.md` 的相位分箱探针可复用。

**纲领 §1.1 的排序据此更新**：资源轴不再是「加厚果层」，而是「等量再分配」；
「加厚」已证伪，不要再试。

### 9.1 为什么这一轮要交叉 `forage_tradeoff` 强度

§6 那条算术更正的直接后果：频率依赖下专精者亚种群比例 `q ≈ f`，**任何果层份额都撑得起
成比例的亚种群**，所以「份额不够」从来不是分化不发生的充分解释。真正卡住的是
**选择梯度 vs 基因流**——而选择梯度由 `forage_tradeoff` 的强度决定，不由 `f` 决定。
`§9.5` 那次只开了 `forage_tradeoff=0.5` 一档，**把强度当常数、只动份额**，因此它的
根因诊断（「无生态位可专精」）是不完整的。本轮把两者交叉。

所以那个归因是错的：塌缩的原因不是「没有饭碗」，是「中间型最优」。**

### 9.9 为什么中间型会最优 [提案，非结论]

**未测量适应度曲面**，以下是解释不是结论：果层的空间位置由
`terrain.py:207` 的 `fruit_capacity = fruit_max × patch × forest² × (1−rock)` 决定——
**果实长在森林里，而森林是中海拔近水带，正是所有个体本来就待的地方**。
两种资源在空间上**交织**而非分隔，于是一个个体在一生中会反复遇到两者，
**「两样都能吃」严格优于「只精一样」**。

专精只有在个体**大部分时间只遇得到一种资源**时才划算。
**→ 资源分割需要的不是「第二个饭碗」，而是「两个饭碗离得够远」。**
这恰好就是用户那句「**局部的**多物种生态箱」的字面含义，也把 backlog 指回**空间轴**：
要么把果层挪出森林带（改 `fruit_capacity` 的地形门控），要么走时间轴（昼夜错峰取食）。
**两者都会改默认世界行为，属于要用户拍板的岔路。**

## 11. R3 等量再分配：同样多的食物，两种吃法（2026-08-03，run_id: 20260803-repartition）

**这不是 R1 的救援臂。** R1b/R1c 测的是「**更多**食物能不能造生态位」——已证伪。
R3 测的是不同的命题：「**同样多**的食物，分成两层供应，能不能造生态位」。
区别是可操作的：R3 **要求总植物通量守恒**，这正是 §10 认定的那条约束。

### 11.1 为什么 R1c 的机制修复现在才派上用场

`fruit_water_frac` 在 R1c 里没能救回护栏（因为破的是承载力不是水口径），
但它是 R3 的**前置条件**：草的水挂能量、果实的水在解耦前只有草的 1/`fruit_energy`，
所以「砍草补果」在旧实现下必然连带砍掉觅食水补贴（探针一 q5 臂渴死升到 52.5% 就是这个）。
水中性剂量 `fwf = 0.10 × fruit_energy = 0.40` 让两层每卡路里供水相等，
**砍草补果才第一次成为一个干净的替代实验**，而不是偷偷同时动了水。

### 11.2 假设与判据（先写后跑）

- **假设**: 存在一组参数使 **总植物通量 `graze_gain + fruit_gain` 守恒**（落在同种子基线的
  [0.90, 1.10] 倍内）而 `frugivory_frac ≥ 0.20`，且 R1b/R1c 那四条护栏**逐种子 6/6 全过**。
- **成功判据**（比 R1c 多一条守恒约束，其余不放宽）:
  中位 `frugivory_frac ≥ 0.20`
  **且** 总植物通量 ∈ 同种子基线 [0.90,1.10]× **6/6**
  **且** `carnivore_frac ≥ 0.05` **6/6**
  **且** `population` ∈ 同种子基线 [0.7,1.3]× **6/6**
  **且** `death_thirst_frac` ≤ 同种子基线 +5pp **6/6**。
- **失败判据**: 无臂全过 → **资源轴整条关闭**（加厚已证伪、再分配也不行），
  backlog 只剩空间/时间轴，写进 `experiments.md` §5 作续判。
- **主旋钮**: 果侧 `fruit_regrow_baseline=0.25 fruit_energy=4.0 fruit_water_frac=0.40`（D 臂配置）
  固定；草侧用 `regrow_baseline`（必要时加 `plant_max`）下调来抵消。
- **先跑定标探针**（单种子、非结论）找抵消剂量，再跑 6 配对种子判决。
- **预标风险**: 砍草会压捕食者（草→食草→食肉的底座变薄），`carnivore_frac` 护栏就是防这个；
  `config.py` 记过 `plant_max=1.2` 会更快饿死捕食者，故优先动 `regrow_baseline` 而非 `plant_max`。
- **git hash**: 见 `outputs/20260803-repartition/verdict/provenance.txt`

### 11.5 为什么不能采信：判据容差 ≈ 1 个复现噪声 SD

分析中派生出一个本轮最重要的量：**同种子、同配置、同代码重跑的散度**。
`A_base seed 0` 重跑 6 次（`outputs/20260803-repartition/replicate/`，主控已独立复核原始 JSON）：

| 指标 | **同种子重跑 SD** | 跨种子 SD（n=6） | 倍数 |
| --- | --- | --- | --- |
| `population` | **146.6**（CV 0.082） | 39.2（CV 0.023） | **3.7×** |
| `carnivore_frac` | **0.0527**（同一 seed 跑出 0.068–0.237） | 0.0131（CV 0.079） | **4.0×** |
| `total_flux` | 19.1（CV 0.079） | 9.6（CV 0.039） | 2.0× |
| `death_thirst_frac` | 0.0428（4.28 pp） | 0.0350 | 1.2× |

代入两条失败的判据：
- **C2 的 ±10% 窗**：比值是处理/基线，分子分母各带一份噪声 → 比值 CV ≈ √2×0.079 = **0.112**，
  即 **±10% 窗 ≈ ±0.9 个复现 SD**。一个真效应为零的配置，逐种子 6/6 落窗内的概率约
  `0.63^6 ≈ 6%`。**C2 作为 6/6 逐种子护栏，与配置好坏无关地几乎必然失败。**
- **C5 的 +5pp 线**：复现 SD 就是 **4.28pp**，即容差 ≈ **1.2 个复现 SD**。零效应下每颗种子
  约 12% 概率自己撞线。

**所以 R3 记为「无法判定」，不是「不通过」。** 这与事后放宽判据的区别是可操作的：
判据数值一个都没改，改的是**测量**——要判它必须先把噪声压下去（每格重复 k 次取均值，
噪声降 √k；或用确定性 XLA 算子）。测量修好之前，R3 的通过/不通过都没有信息量。

**§11.2 的失败判据（「无臂全过 → 资源轴整条关闭」）因此不执行**：它的隐含前提是判据可测，
而该前提被违反。资源轴**挂起**，不宣布关闭，也不宣布成功。

### 11.6 仍然可信的三件事（效应量远超复现噪声）

## 12. 【下一轮执行计划】把果层挪出共居带（用户已拍板，2026-08-03）

**先决条件：`docs/run_to_run_variance.md §7` 的新统计协议必须先落地**（12 种子 × 2 重复）。
否则本轮判决会重蹈 R3「判据容差 ≈ 1 个噪声 SD」的覆辙。

### 12.1 病根定位到了具体一行

§9.9 的诊断在代码里能指到确切位置。`terrain.py`：

```
water_prox = exp(-water_dist / forest_water_scale)      # 离水越近越大
forest     = elev_band * water_prox                      # 森林 = 中海拔 ∩ 近水
fruit_capacity = fruit_max * patch * forest**2 * (1-rock)
```

**果层的栖息地项是 `forest²`，而 `forest` 本身就是「离水近」做出来的。**
于是果实必然长在所有个体本来就挤着的那条河岸林带里——两种食物在空间上完全交织，
个体一生反复遇到两者，「两样都能吃」严格优于专精。**稳定化选择不是 bug，是这个几何的正确解。**

### 12.2 手术：给果层一个可调的「干旱」栖息地项

**[提案] 最小改动**，`terrain.py` 那一行改成两项的加权混合：

```
dry = smoothstep((water_dist - fruit_dry_d0) / (fruit_dry_d1 - fruit_dry_d0))
habitat = (1 - w) * forest**2 + w * dry          # w = cfg.fruit_dry_weight
fruit_capacity = fruit_max * patch * habitat * (1-rock)
```

- **`fruit_dry_weight` 默认 0.0 → `habitat` 恒等于 `forest²` → 世界逐位不变、golden 不动。**
- `w=1` 时果层完全由「离水多远」决定，与森林脱钩。
- `fruit_dry_d0/d1` 控制干旱带从哪里开始（单位是世界单位，参照
  `river_half_width=16`、`herb_water_dist` 基线约 10–25）。
- **必须补的单测**：`w=0` 时 `terrain.build` 的 `fruit_capacity` 与旧实现逐元素相等。

### 12.3 阶段与闸门（前一阶段不绿不许进下一阶段）

**A｜零成本先量重叠度（不写代码）。** 现在果层和种群到底重叠多少？

**共居在默认世界是几何的，在厚果层世界是行为的。§12.5 的读法要按 `niche` 写。**

**[本世界实测] C/D 的基线固定为 `niche` 臂**，三条定量理由：
1. **`base` 没有可下降的量。** 它离零模型只有 +0.0089，而本设计 p≤0.05 口径的 MDE 是

2. `base` 的 `frugivory_frac = 0.0011`，§12.3 C 三读数之一「会不会塌回 0」在那里**已经是 0**，

3. D 的参照系 §9.6 的 −38.3% 就是在厚果层世界测的。

**[本世界实测] 分辨率**：12×2 在 `niche` 主口径上，重叠度下降 20% 的功效是 **0.999**，

**[本世界实测] 三条对我自己预注册口径的更正**（analyst 主动提的，都成立）：

1. **`sel_ratio_water` 单独回答不了「种群被挪走了没有」。** 它的零模型用的是**实测个体

   43.08）。C 的读数从三个扩到五个。
2. **`frac_in_fruit` 的「有效格」阈值是场最大值的 5%，而场最大值会随手术改变**，
   手术前后比的是不同的格集合。**必须与 `fruit_cells_eff` 一起读。**
3. **`schoener_d` 的预注册警告要更新**：它在 `base` 里被证实（D 0.1138 < 零模型 0.1210，

   不是普遍现象，而是「果层没人吃时」的现象——在 C/D 实际发生的 `niche` 世界里，D 可用。

**[本世界实测] §12.4 风险 1 的读法要改。** 预标写的是「最可能的结局是没人去吃」。但
`niche` 世界的种群扣掉水距后仍以 3.71× 追踪果层，**更可能的失败模式是它们跟着果层走进

`frugivory_frac` 塌。`measure_overlap.py` 已补上全程累加的死因份额。

- ⚠️ **跨臂差不能归因给单一变量。** `niche` 是 5 项一起改的捆绑
  （`fruit_energy`/`fruit_regrow_baseline`/`fruit_water_frac`/`plant_max`/`regrow_baseline`），
  这是 R2 起就在用的那套。「变值钱就往上挪」只能写成「这套捆绑配置下」。
- ⚠️ **48 个 run 全在同一张地图上**（`fruit_cap_total` 只有一个取值）。本轮**全部指标都是
  空间性的**，所以结论只对**这一条河系**成立——**§12.3 E 的跨地形交叉是必须的，不是可选的。**

### 12.3.B B 阶段落地（2026-08-03）：旋钮已装，默认关且 bit-exact

`underworld/terrain.py` 的 `fruit_capacity` 那一行改成走一个 `habitat` 项，
`Config` 加三个字段：`fruit_dry_weight`（默认 **0.0**）、`fruit_dry_d0` / `fruit_dry_d1`。
**默认 0 时整个分支被跳过**，字段逐位不变、`golden` 未动（`check.py` 41 项绿）。

**实现上对 §12.2 的两处偏离，都写下来**：

1. **编译期门控，不是纯算术混合。** §12.2 提的是 `(1-w)*forest² + w*dry`；改用
   `if cfg.fruit_dry_weight > 0.0:` 包起来，与 `dynamics.graze` 里 `forage_tradeoff` 的
   写法一致。理由：`w=0` 时那行代码根本不执行，bit-exact 是**构造保证**的，而不是靠
   「`0.0 * dry` 恰好等于 0」——后者在 `dry` 出现非有限值时不成立。
2. **加了容量归一化（这条是必须的，否则 C/D 无法归因）。** 装上旋钮先量了一遍形状，
   发现 blend 到 `w=1` 把**果层总承载从 536.8 抬到 1026.3，+91%**。原因：`forest²` 在
   几乎所有格上都很小（窄带再平方），而 `dry` 在四分之一张图上饱和到 1，所以任何朝 `dry`
   的混合都顺带加厚果层。**那样的处理臂同时是「挪开了」和「厚了一倍」，任何效应都归因不了**
   ——而「加厚果层」已是被证伪的关闭路线（§8.3、`experiments.md` §5），也是 §12 明写的
   非目标。归一化后总承载逐点相等（+0.000%），空间挪动不受影响。**这与 §11 等量再分配是

### 12.4 预标风险（先写下来，别事后解释）

### 13.1 病根：实现与自己声明的设计意图反号 [对应]

八个回合动的一直是**果层**（加厚 §5–§8、等量再分配 §11、空间分隔 §12）。
§12.3.C 判负时自己指出了唯一没走过的方向：**能挪的只有果层，而另一个饭碗无处不在。**

`config.py` 在 `fruit_max` 上方写着这个世界为什么要有果层，原文：

> "Forests hold far more total biomass than grassland but far *less* that a grazer can
> eat -- woody, tough, defended, **with the canopy shading out the herb layer**. That is
> why savanna carries the large-herbivore biomass and rainforest does not. … **canopy is
> not simply "more food" here; it is a low grazing floor with a high-value exception
> scattered through it**."

而 `terrain.py` 写的是 `fertility = grass_base + forest_bonus * forest`，`forest_bonus = +0.35`：
**满冠层的草承载是空地的 1.538 倍——林冠是全世界草最肥的地方。**
注释说林下应当是「低放牧底」，代码给的是「最高放牧顶」。

**这不是调参分歧，是实现与注释反号。** 而这一个正负号，正是三轮资源分割实验死在的那个几何：
果层由 `forest²` 门控长在林冠里，林冠又是草最肥的地方 ⇒ 两种资源完全共址 ⇒
「两样都能吃」严格优于专精（§9.6 / §9.10 / §9.11 实测的中间型最优）。

**注意与 `experiments.md §5.6` 提案的符号相反**：那里写的是「压 `grass_base`、**抬**
`forest_bonus`」。抬 `forest_bonus` 会让草**更**集中在果实所在处，加重重叠。
本轮走的是相反的符号。

### 13.2 第二处：`water_dist` 是「到最近**河**的距离」，不是它声称的「到最近河/海的距离」[对应]

**[核查记录] 本节措辞被 `claim-verifier` 收紧过一次。** 我最初写的是「实现与两处注释都不符」，
那是过度声称：**喝水那半是对的**。收紧后的正确措辞如下。

- `terrain.py` 是 `jnp.where(is_sea, 0.0, d_river)`：海格归零，陆地格一律读 `_dist_to_rivers`
  的结果，**到海的距离从未被计算**。`Terrain.water_dist` 的字段注释
  `distance to nearest river/sea` 因此对全部 13568 个陆地格都是错的。
- `build()` 里那段注释**半真**：
  - **喝水这半成立** —— `dynamics.py` 查 `wd < river_half_width`，站上海格 `wd=0` 就能喝，
    `underworld/` 里也没有任何地方拦住个体走进海。
  - **水感这半只在岸线一格内成立** —— `sensors.py` 每扇区只在 `food_sample_dist=9` 处采一格，
    采样点落进海格才读到满值。**所以海在陆地上没有距离梯度，只有岸线处的一个阶跃**，
    有效探测距离约 11 世界单位，而河是 `vision_radius + food_sample_dist = 30`。

  该提交信息未提及此事；`docs/` 全量检索无任何「海不提供水距梯度」的决定。反向证据两条——

### 13.3 手术：两个默认关、bit-exact 的旋钮（`2bb48e0` 已落地）

1. **`grass_shade`（默认 0.0）**——`fertility = clip(grass_base + forest_bonus·forest
   − grass_shade·forest, 0, None)`，随后**等量归一化**。照抄 `fruit_dry_weight` 已确立的
   纪律：**只挪不加，把「在哪」和「有多少」分开**。
2. **`water_sea_dist`（默认 False）**——`water_dist = min(d_river, d_sea)`。

**`grass_shade ≤ 1.0` 有一个零代码等价实现，已收进单测当独立对照**：`forest_bonus` 没有
clamp、全仓唯一消费者就是那一行，所以 `grass_base + (forest_bonus − s)·forest ≡
grass_base + forest_bonus′·forest`，两条路径只差一个被归一化除掉的全局标量。
**旋钮真正挣到自己位置的是 >1.0 那段**——那里 `clip(...,0,None)` 才生效，
而那个 clip 是「有果实、没有草」**唯一**的来源（零草陆地格 5.0% → 11.4%）。

### 13.5 种群实验设计（先写后跑）

**世界（全部四臂共用）**：`niche` 厚果层配置，出处 `outputs/20260803-partition/provenance.txt`
——`fruit_regrow_baseline=0.25 fruit_energy=4.0 fruit_water_frac=0.40 regrow_baseline=0.010
plant_max=2.0`，**外加 `water_sea_dist=1`**。
**为什么不是默认世界**：§12.3.A' 已判定——默认世界里果层与种群的重叠是纯几何的，
可下降空间 ÷ MDE 只有 0.52，手术做对了也测不出来。

**设计**：2×2 因子（`grass_shade` × `forage_tradeoff`），**12 种子 × 2 重复 = 96 run**，
20000 步，并发 6。

| 臂 | `grass_shade` | `forage_tradeoff` | 是什么 |
| --- | --- | --- | --- |
| `N0` | 0.0 | 0.0 | 平世界 + 中性漂变（基因被编译期断开） |
| `T0` | 0.0 | 1.0 | 平世界 + 最大选择强度（≈ §9.6 的条件） |
| `N1` | 1.3 | 0.0 | 结构世界 + 中性漂变 |
| `T1` | 1.3 | 1.0 | 结构世界 + 最大选择强度 ← **处理臂** |

**为什么 `forage_tradeoff` 必须是因子而不是常量**（`plan-critic` 拦下的第一个 BLOCKER）：
§9.6 的基线不是「方差多大」而是「**处理臂比中性漂变窄 38.3%**」。没有同世界的中性对照，
「方差变大了」这句话无法成立——不同世界的漂变方差本来就不同。
`forage_tradeoff` 默认 **0.0**，此时基因对采食零效应（`config.py` 明写 "ZERO effect"），
照 §12 那样只跑 sea × shade 会让 96 个 run 全是纯漂变，什么都判不出来。

**主判据（先写后跑）**——**交互项**，每个种子一个数：

    d_s = (T1_s − N1_s) − (T0_s − N0_s)

- **H1 形状** —— `forage_pref_std` 的 `d_s`：12 格均值配对 Wilcoxon 双侧 p ≤ 0.05，
  方向 ≥10/12，**且报出效应 ÷ 本实验自估的 `√2·σ̂_W/√r`**；比值 <1 即标注功效不足，
  **即使 p 过线**（`conventions.md §5`）。
- **H2 形状** —— `blrt_lr_per_n` 同上。
- **H3 空间（本轮新增，这才是「局部多物种」的字面含义）** ——
  个体的 `forage_pref` 与它所在格「果实能量份额」的加权相关 `ρ_space`。
  零模型 = 把个体位置随机置换 200 次（保持基因值与占据格的边缘分布）。
  预测：T1 的 `ρ_space` 显著 > 0，且 `d_s(ρ_space) > 0`。
  **H1/H2 说「基因分开了」，H3 说「它们住在不同地方」。只有 H3 成立才算生态位分化。**

**护栏（容差一律对着本轮 `N1` 臂自估的 `√2·σ̂_W/√r` 定，不凭直觉——§11.5 就是因为拿
±10% 当容差而判成「无法判定」）**：

- `death_thirst_frac` —— 历次破得最多的一条（§7 破 2–3/6、§8 三臂全破、§12 +37.6%）。
  容差 2 SE。
- `frugivory_frac` —— §12.4 风险 1 的拦截：林下无草之后没人进林子，就是把果层删了。
- `carn_speed` / `herb_speed` —— 风险 1（峰值 +39% ⇒ 伏击优于追击）的**指定读数**，
  `config.py` 的 `plant_max` 调优记录用的就是「食肉者平均速度是否向食草者靠拢而不是衰减到 0」。
- `carnivore_frac` / `population` / `min_pop` —— 灭绝与超调。

**尺子警告（`plan-critic` S-1）**：`herb_water_dist` / `carn_water_dist` / `water_bound_frac`
/ `inland_frac` 全部由 `terrain.water_dist` 算出，而认海换了这把尺子。四臂之间可比
（尺子相同），**但一律不得与 §12.3.A 归档的 `herb_water_dist=45.4`、`conventions.md §7` 的
`inland_frac` 零模型并列**。跨臂报这四个量时另用默认（river-only）水距场固定尺子再算一遍。

**失败判据与放弃条件**：

- H1 与 H2 都不成立 ⇒ **「空间分隔造生态位」整条路线关闭**，连同 §12 的负结果一起升级写进
  `experiments.md`，结论改为「在这个世界里资源分割不可达，下一步只能换轴（营养级 / 时间）」。
- H1/H2 成立但 H3 不成立 ⇒ **性状分化而非生态位分化**，单独记，不得当成多物种。
- **渴死若再次逐种子破半数，按 §12.5 收口，不降 `grass_shade` 剂量重试。** 剂量重试是

### 13.6 预标风险（先写下来，别事后解释）

1. **等量归一化把草层峰值从 2.195 抬到 3.051（+39%）。** `config.py` 的 `plant_max` 有一整段

### 13.7 判决（2026-08-03，96 run 全部完成、0 错误）

**判决全文在 `docs/multispecies_feasibility.md` §10**（结论归专题文档，纲领只留判决行）。
一句话：**分离做到了，物种没做出来**——遮荫世界里选择造出了稳健的生态型—生境关联
（原始 r：`T1−N1` = −0.2697，**12/12**，p=0.00049 地板，效应/噪声 −1.672，本纲领第一个

**方向性选择 + 空间分选 = 一条 cline，不是分歧选择，不是两个物种。**

- **H1 / H2 判 undecidable（功效不足，功效 0.159 / 0.216）**，故 §13.5 那条

- **§13.5 的 H3 符号写反了**：`forage_pref` 是**草**偏好基因
  （`dynamics.py`：`grass_mult = 1 + tradeoff·(2·pref−1)`），所以实测的负号才是生境匹配方向。
  代码与数据两条独立证据见 §10.3。
- **主控一句结论被复核推翻**：不能说「稳定化塌缩被地形解除了」——那句和交互项
  （p=0.339）是同一件事，且 `T1−N1` 的 CI 含平世界的塌缩量。诚实版本见 §10.5。
- **根因量化**：果层只占陆地能量的 **11.15%**（草承载 18828.7 vs 果承载×4 = 2362.8，
  实跑配置 `plant_max=2.0`）。一个数一次解释完三个结果。
  **下一轮的自变量是果层能量占比，不是分离度**——分离度已到顶（果富格草量中位 0.000×）。

## 14. 【R10】权衡前沿的曲率（2026-08-03，run_id: `20260803-curvature`）

**结论归 `multispecies_feasibility.md`；本节只放预注册的判据、MDE 与失败判据，跑之前提交。**

### 14.1 假设

`feasibility.md §11.1`（代数）：直线权衡前沿 ⇒ `W(s)` 对 `s` 线性 ⇒ `d²W/ds² ≡ 0`，
中间型永远不可能是适应度极小值。`forage_curvature = k < 1` 把前沿弯向原点，
**应当**把中间型变成极小值，从而第一次让分歧选择有一阶项可以来自。

### 14.2 主判据改了，理由是实测的估计量精度（不是事后挑口径）

R9 的教训是「护栏容差对着噪声定了、主判据没算 MDE」。本轮先跑了一个
**只含参照臂的噪声标定 pilot**（`outputs/20260803-curvature/pilot/`，k=1.0，4 种子 × 2 重复；
**只有一个臂，不含任何处理效应信息，因此不会污染判决**）：

| 读数 | 参照臂均值 | `σ_within` | ICC | 配对噪声 | **MDE(n=12, 80%)** |
| --- | --- | --- | --- | --- | --- |
| `quad_intake` | **+0.0004** | 0.00274 | 0.000 | 0.00274 | **0.0057** |
| `quadrel_intake` | **+0.0077** | 0.02909 | 0.000 | 0.02909 | **0.0607** |
| `quad_demog` | — | — | — | — | 4 格里只有 2 个有效，**弃用为主判据** |
| `sd`（取自 R9） | 0.0893 | 0.02545 | 0.215 | 0.02545 | 0.1126（**基线的 126%**） |
| `blrt_lr_per_n`（R9） | 0.4860 | — | 0.460 | — | 1.467（**基线的 302%**） |

**两条决定**：

1. **主判据 = `quad_intake`（个体级回归 `last_food ~ 1 + z + z²`，n≈10⁶）。**
   它是被操控的量**本身**，MDE 0.0057；而 `sd`/`blrt_lr_per_n` 是它的下游后果，
   MDE 分别是基线的 126% / 302%——R9 已经用 96 个 run 证明那两个测不出中等效应。
2. **`quad_demog` 不当主判据**，因为第一版估计量在 4 个格里只有 2 个能凑够有效箱。
   已修（前后各 1/4 帧合并做直方图、按 √n 加权、门槛与掩码统一），**降为次判据**。

**参照臂读出 +0.0004（≈0）本身就是 §11.1 的独立经验确认**——4 种子 × 2 重复，不是单 run。

### 14.3 设计

**世界**：R9 的结构世界 —— `niche` 厚果层 + `water_sea_dist=1` + `grass_shade=1.3`。
**臂**：4 个 × 12 种子 × 2 重复 = **96 run**，20000 步烧机 + 6000 步采样。

| `K10` | 1.0 | 1.0 | 刀刃（今天的直线前沿），§11.1 预测 ≈0 |
| `K05` | 1.0 | 0.5 | 处理臂 |
| `K035` | 1.0 | 0.35 | 剂量项，测单调性 |

### 14.4 可证伪预测（先写后跑）

- **H1（主）** `quad_intake`：`K05 − K10 > 0`，配对 Wilcoxon p ≤ 0.05，方向 ≥10/12，
  **且效应 ÷ 本实验自估的 `√2·σ̂_W/√r` ≥ 1**（比值 <1 一律标功效不足，**即使 p 过线**）。
- **H2（剂量）** `quad_intake` 随 `k` 下降单调上升：`K035 > K05 > K10`。
- **H3（估计量对照）** `N` 与 `K10` 的 `quad_intake` 都与 0 无显著差异。
  **这一条不成立则整轮读数作废**——说明估计量在测别的东西。
- **H4（下游，弱预期）** `sd` / `bimodality_coefficient`：`K05 > K10`。
  **明写在此：本设计对 H4 功效不足**（`sd` 的 MDE 是基线的 126%），
  所以 H4 不成立**不构成**「分布没变宽」的证据，只能报 undecidable。

### 14.5 护栏（容差 = 2 × 本轮自估的 `√2·σ̂_W/√r`）

`death_thirst_frac`（R9 已在 T1 涨到 0.5925）、`carnivore_frac`（R9 已 −40.3%、24 个 run 里
2 个为 0）、`population` / `min_pop`（**k<1 抬高专精者的总摄入 ⇒ `experiments.md §5`
「加食物只会变成更多身体」在此适用**，这是本轮头号风险）、`frugivory_frac`、`carn_speed`。

### 14.6 失败判据与放弃条件

- **H1 不成立且效应/噪声 ≥1** ⇒ 曲率手术**证伪**：弯前沿改不动实测适应度曲面。
  那么 `feasibility.md §11` 的代数虽然对，但被别的项主导，**整条「造分歧选择」路线关闭**。
- **H1 不成立但效应/噪声 <1** ⇒ **undecidable**，报 MDE，不许读成阴性（R9 的教训）。
- **H1 成立但 H4 不成立** ⇒ **曲面弯了、分布没分开** ⇒ 瓶颈是**基因流**，
  下一轮是局部交配（实测配偶距离 / 随机零模型 = 0.966，见
  `explorations/20260803-shade/probe_mate_distance.py`）。**这一格是本轮最可能的落点。**
- **不许因为结果不好看就降 `k` 再试一轮** —— 剂量已经在设计里（`K035`）。

### 14.7 判决（2026-08-03，96 run 全完成、0 错误）

**判决全文在 `docs/multispecies_feasibility.md` §12。** 一句话：
**不是「弯前沿没用」，是「弯前沿能注入的曲率比这个世界本来就有的负曲率小一半」。**

- **§14.6 触发第二档 undecidable**（H1 比值 0.717 < 1），**不得读成证伪，也不构成显著反向**。
- **但这是一种「补功效也没用」的 undecidable**：假设自身预测的效应 +0.001839 ÷ 本轮 MDE
  0.008787 = **0.209**；且即使 100% 交付，`W''` 仍是 −0.050（K05）/ −0.023（K035），依然凹。
- **H3 成立**：估计量对照 N 读 **+0.00003（t=0.06）**。
- **主控被纠正三处**（平衡态反证无效、过冲机制不成立、供给饱和才是更简单的解释），见 §12.4。
- **方法学账**：§14.2 的 pilot **低估噪声 54%**（`σ_within` 0.00274 vs 本轮自估 0.00421）——
  8 个 run 估出的 `σ̂` 自由度只有约 4，**下次拿 pilot 定 MDE 要用置信上界，不是点估计**。
- **下一步不是降 k**（§14.6 的禁令维持，且算术显示打平即止），是**攻基线凹度**：§12.8。

### 15.3 主判据与 MDE（口径已按审查修正两处）

**主口径 = 交互项** `(T05 − N05) − (T15 − N15)`，噪声 **`2·σ̂_W/√r`**
——**不是 `√2·σ̂_W/√r`**：四个格均值各贡献一份独立噪声。
主控第一版用了 `√2`，把全部 `预测÷MDE` 虚高 **1.414 倍**。

`σ̂_W` 一律乘 **`sqrt(df / χ²₀.₁₀(df))`** 取 90% 置信上界（`MEMORY.md [LEARN:stats]`：
R10 的 pilot 因为用点估计低估噪声 54%）。**噪声只从预测不会触底的臂池化**
（`N15`/`T15`/`N05`/`N05m`），因为 `dip_ratio` 在处理臂会塌到地板，
把地板池化进去会压低噪声、虚高比值（`exp_stats.pooled_within_sd` 的 docstring 就是这么写的）。

| --- | --- | --- | --- |

| `frac_mid` | −0.659 | 1.78 / 1.18 | 描述量（分不出「裂开」与「移走」，见 15.4） |
| `bimodality_coefficient` | +0.357 | **0.74 / 0.49** | **预声明功效不足** |

### 15.4 `dip_ratio` 的构造、它的边界，以及一处诚实标注

`dip_ratio` = 中间带 `pref ∈ [0.40, 0.60]` 的实测占比 ÷ **同均值同 sd 的高斯**在该带上的期望。
位置与尺度都被除掉 ⇒ **任何单峰分布按构造读 ~1，真分裂读 ~0**。

- **它自带估计量对照**：两个中性臂必须读 ~1（实测 N15 = 0.837）。这比在预注册里写一句
  「本读数是看了图之后想出来的」更硬——**但那句自白照样要写，见下**。
- **为什么不用 `frac_mid`**：探针里 `S1`（真分裂）读 0.0006、`S2`（只是整体右移到 0.70）读
  0.058，**两者都近乎空，`frac_mid` 分不出**。`dip_ratio` 分得开（0.0031 vs 0.862）。
- **[诚实标注] `dip_ratio` 与它的带宽 [0.40, 0.60] 都是在看过探针直方图之后才定的。**
  探针是独立数据，本轮是新实验，所以这样用合法；但**带宽在开跑前已冻结**，事后不得调整。
- **边界（必须写死，否则会被下一轮引用过头）**：`dip_ratio ≈ 0` 只证明「中间带被掏空」，
  **不证明存在两个有质量的生态型**。后者由 `low_mass` 承担，而本设计对它
  **预声明功效不足（0.18）**——逐 run 从 16‰ 到 393‰，同种子两次重复能差 10 倍。

### 15.5 归因闸（本轮真正要回答的问题）

`(T05m − N05m) − (T15 − N15)` 与主判据同号同量级 ⇒ **起作用的是需求量级**（饱和/竞争强度），
兑换率无关；**只有 `T05` 塌而 `T05m` 不塌** ⇒ **起作用的是兑换率**，
即「降 `eat_rate`」这个操作**直接改了被研究的那根轴**，双峰是操作的产物而非生态的产物。

**这一格是本轮的重点。** 不设这一臂，96 run 拿到的正结果无法归因。

（0.333→0.382，**方向是「更多人吃果」，与 §13.6 风险 3 相反，属良性**）、

### 15.7 失败判据

- **主判据不成立且比值 ≥1** ⇒ 双峰不可复现，探针是 n=4 的假象，**这条路关闭**。
- **主判据不成立但比值 <1** ⇒ undecidable，报 MDE，**不许读成阴性**。
- **主判据成立但归因闸判为「兑换率」** ⇒ **双峰是操作产物**，
  必须写成负结果：`eat_rate` 悄悄改了被研究的轴，不是生态发现。
- **主判据成立且归因闸判为「需求量级」** ⇒ 本纲领第一个可复现的分歧选择，
  下一轮的问题变成「两个模态能不能维持成两个物种」（那时局部交配才重新有意义）。

## 16. 【R13】少数簇是稳定多态还是走向固定的暂态（2026-08-04，run_id: `20260804-traj`）

**结论归 `multispecies_feasibility.md`；本节只放预注册判据，跑之前提交。**

### 16.1 群体遗传学的零假设：有效种群不是普查种群，差 15 倍

`forage_pref` 是单基因、sigmoid 映射、`mutation_sigma=0.02`、参与 crossover ⇒ 单倍型 WF。
中性臂 `N05` 实测 `sd(pref)=0.0862`、`mean_pref=0.4867` ⇒ 基因位方差 **0.1189** ⇒
突变—漂变平衡 `V* = 2·Ne·σ_m²` 解出 **`Ne ≈ 149`**——**不是普查种群 2300**。

⇒ p=0.13 的中性丢失期望 `2Ne·(p/(1−p))·|ln p| ≈ 91 代`。
实测世代长 **169 步/代**（`trajectory.py` 直接读 `state.generation`，不再是假设）
⇒ **中性丢失期望 ≈ 1.5 万步**。

**[本世界实测] 旁证，而且它是本轮最强的先验**：`T05` 跑了 26000 步 ≈ **1.7 个丢失时间**，
而 **24 个 run 里 8 个 `low_mass` 恰为 0**（逐 run 排序 `[0×8, 0.004, 0.035, …, 0.433]`）。
**这正是中性预期。** 所以「少数簇是稳定多态」这个假设，面对的是一个很强的零假设。

### 16.2 两个 BLOCKER 改掉的设计（`plan-critic`）

**主判据不能是「`low_mass` 对检查点的斜率」**：`T05` 的 `low_mass` 臂均 0.1264、
池化格内 SD 0.1251（**噪声/均值 = 0.99**），ICC 只有 0.22；而该设计的「阳性答案」是
「不拒绝斜率 = 0」——**在 1/3 样本已贴地板的读数上，「斜率≈0」既是稳定多态的预测，
也是「早就没了」的预测。**

**入组条件必须写在跑之前**：那 8 个从一开始就没有少数簇的 run 会贡献「斜率恰好 0」，
与稳定多态同号同值，直接把结论推向假阳性。

### 16.3 设计

**世界**：R11 的 `T05`（`niche` 厚果层 + `water_sea_dist=1` + `grass_shade=1.3` +
`forage_tradeoff=1.0` + `forage_curvature=1.0` + `eat_rate=0.5`）。
**100000 步，5 个检查点**（20k/40k/60k/80k/100k），每个检查点一个 2000 步窗。
**2 个地形 × 12 种子 × 1 重复 = 24 run**（`ridge_wavenumber ∈ {1,2}`）。

**[诚实标注] 地形因子换的是河系的空间排布，不是资源丰度**：实测
`wn=1` 果能占比 11.15%、`wn=2` 是 11.17%。所以它能脱离「这一条河系」的伪重复，
但**「草:果 ≈ 11%」仍然是本轮未测的固定边界**——而 §13.7 判定那个比值恰恰决定
少数簇能占多少质量。

**入组条件（写死）**：第一个检查点（t=20k）的 `split_score > 0`。
不满足的 run **不进主判据**，但要单独报「在 20k 之前即丢失」，并计入留存曲线的分子分母。

### 16.4 三个互斥的可证伪预测

主判据是**回复力**，不是「频率变不变」——**稳定多态与中性共存的区别不在频率变不变，
在受扰之后回不回来**，而不同种子/检查点自然落在不同频率上，无需人为扰动：

| 假设 | 预测 |
| --- | --- |
| **H_stable**（负频率依赖，真多态） | 逐 run「少数簇 `dlog` 对少数簇频率」的斜率 **< 0**，且 `mean(dlog) ≈ 0` |
| **H_neutral**（中性共存） | 斜率 **≈ 0** 且 `mean(dlog) ≈ 0` |
| **H_transient**（走向固定） | `mean(dlog)` 显著 **< 0**（与频率无关或正相关） |

**判据**：24 个逐 run 斜率做符号秩检验对 0；`mean(dlog)` 同法。报效应/噪声比，
**比值 <1 一律判 undecidable**。

**[必须写明] 本轮无法预先算出 MDE。** R10/R11 的教训是「预注册要写预测效应 ÷ MDE」，
但这个统计量**没有任何先验数据**（逐箱 `dlog` 是 `f5f4378` 才装的），
噪声结构也与跨臂比较完全不同（时间序列 vs 跨种子）。
**所以本轮的 MDE 与效应/噪声比都从本实验自估，且预先声明：若比值 <1 则判 undecidable，
不许读成「稳定多态」**——那正是 R10 吃过的亏，只是方向相反。

### 16.5 护栏（R11 已证明「臂均 ±X%」是空转，改成轨迹）

**逐检查点报** `population` / `carnivore_frac` / `min n_herb` 的**轨迹**，不设臂均容差。
预注册：**若 >4/24 个 run 在 t<100k 失去捕食者，则晚期检查点测的是另一个世界，
分开报，不许池化。**

**已修一个真 bug**：`fitness_surface.py` 在种群崩溃时不报错也不打印 `collapsed to zero`
（`herb` 全 False ⇒ NaN，照样打 JSON），于是 `exp_stats.RunSet.load` 的崩溃自检不触发。
`trajectory.py` 每个采样点检查存活食草者数，低于 30 就打印并中止。

**[烟测观察，非结论]** seed 0 跑 14000 步：`low_mass` 0.118 → 0.052，
而**食草种群同期从 2979 掉到 1508**。⇒ **R11 用的 20000 步烧机可能还没到平衡**，
本轮的 5 点轨迹会直接给出答案。

### 16.6 判决（2026-08-04，24 run × 100k 步，0 崩溃）

**判决全文在 `docs/multispecies_feasibility.md` §14。**
**少数簇是弱确定性淘汰下的暂态，不是多态。按现规格关闭这条路线。**

- **`H_stable` 判负**：**0/15 个 run 连续保住分裂**；`low_mass` 全 24 run 0.1447→0.0278
  （p=0.0036）；2 个「幸存者」都是**复活**（6/24 复活，留存不是吸收态）。
- **`H_neutral` 也判负**：`result-analyst` 自建模拟零假设，中性预测 cp4 应停在 0.127，
  实测 0.028，单侧 **p=0.0027**（@ 定标 `Ne=297`）。**⇒ 主动淘汰，不是漂变。**
- **§16.1 的零假设错了两处，两处都让中性太宽松**：`Ne` 是 **297–400** 不是 149；
  复发突变下**两等位基因 WF 丢失模型不适用**，正确零假设是**鞅**。世代长 206–220 不是 169。
- **§16.4 的主判据是设计失败**：反解 `s=0.0041/代` ⇒ 2000 步窗只有 9.7 代 ⇒
  单格信噪比 0.051，**要达功效需约 388 个 run，按设计欠功效约 40 倍**。
  替代是**轨迹积分量**（积 375 代而不是 10 代）。
- **`split_score` 有真假阳（8/37 谷在主峰内，最坏 `split_score=0.41` 而 `low_mass=0`）
  与真假阴（10 格，最大 `low_mass=0.367` 读成 0）**，必须加位置约束或换 `low_mass` 阈值，
  可在 R11 的 144 个存档 run 上零成本复验。
- **两处判据违规已写明不藏**：留存曲线分母主控用错（应为 24）；
  `low_mass` 的比值 −0.66 按 §16.4 字面也不过线，用它下判断的理由已写在 §14.10。
- **`r=1` 让 §16.4 内部不自洽**（无法自估 `σ̂_W`），下一轮必须恢复 `r=2`。

**唯一还值得烧 GPU 的一轮**：**扫草:果比（50:50 / 30:70），不是再变地形。**
§13.7 点名它是决定性变量、§16.3 承认它固定在 11%、此后从未被扫过。
**若 50:50 下仍衰减 ⇒ 实质判负、整条路线关闭；若停止衰减 ⇒ R9–R13 量的是资源丰度伪影。**

### 17.1 前提：两处必须先更正的口径

### 17.4 判据与功效（**两条都要读完再看结果**）

**[必须写明] 本轮对 H1 没有先验数据**——探针只有 1 个检查点，给不出 `Δ`。

## 18. 【R14 Stage 2 / 方案 B】把捕食者通道固定住再问资源比（2026-08-04，run_id: `20260804-ratio2`）

**用户已拍板执行方案 B。** 结论归 `multispecies_feasibility.md`；本节只放预注册判据，跑之前提交。

### 18.1 为什么要这一轮：Stage 1 的两个失败都必须一起修

`feasibility.md §15` 判定 Stage 1 **既不判负也不支持**，两个原因：

1. **主判据的输入坏了**——`BINS=linspace(0.15,0.85,15)` 把窗外个体从分子分母同时剔除，
   `R50` 在 cp1 有 **58%** 的个体在标尺之外。**已修**（`b06319e`：`BINS=linspace(0,1,21)`，
   并把**窗内比例升为一等读数 + 有效性闸** `in_window<0.95 ⇒ readout_valid=False`）。
2. **臂间差被捕食者丢失完全解释**——在**配比完全没动**的 `R38` 里，3 个丢失捕食者的 run
   就复制出了整个 `R50` 图景（Δ=−0.374 vs kept −0.020）。

### 18.2 手术：`diet_delta > 1` 由构造关掉捕食

猎物必须比攻击者食草 `diet_delta` 以上，而 `diet ∈ [0,1]`
⇒ **`diet_delta=1.5` 时不存在合格猎物**。实测验证（2000 步）：
`carn_frac` 0.1273 → **0.0000**、累计捕食死亡 1146 → **0**、`hunt_success` 0.857 → **0.000**。

**这不是「调低捕食」，是结构性关闭**，与任何基因都不交互，两臂**由构造**相同、方差为零
——这正是「把通道固定住而不是事后筛」的字面含义。

### 18.3 设计

**世界**：Stage 1 的世界（`fruit_energy=4.0` + `fruit_water_frac=0.40` + `plant_max=2.0` +
`water_sea_dist=1` + `grass_shade=1.3` + `forage_tradeoff=1.0` + `forage_curvature=1.0` +
`eat_rate=0.5` + `ridge_wavenumber=1`）。**42000 步，2 个检查点**。

| --- | --- | --- | --- |
| `R38p` | 0.25 | 0.010 | 0.15（默认，有捕食者） |
| `R50p` | 0.50 | 0.005 | 0.15 |

**[必须先读完再看结果] H1 的功效声明**：若真实效应就是 Stage 1 观察到的 **+0.026**，
本设计**严重功效不足（比值 0.11）**。但那个 +0.026 是在**混杂世界**里测的
（`R50` 13/24 丢失捕食者），方案 B 的 `n` 臂消除了该混杂，效应**可能大得多**
——**而我没有任何先验数据**。
⇒ **MDE 与比值一律从本实验自估；比值 <1 时判 undecidable，
既不许读成「衰减停了」也不许读成「衰减照旧」**（`feasibility.md §15.2` 的对称规则）。

**H0 不成立 ⇒ 杠杆没生效，整轮读数作废。**

### 18.5 有效性闸（新增，这是 §15 那个失误的制度性修复）

**任一 run 的 `readout_valid=False`（`in_window < 0.95`）⇒ 该 run 的分箱读数一律不可用。**
若某臂 >2/24 个 run 失效 ⇒ **该臂的分箱判据整体作废**，只保留不分箱的 `mean_pref` / `sd`。
**这一条让 §15 那类截断失误不可能再静默发生。**

### 18.6 总通量当协变量，不试图对齐

Stage 1 证明 `frugivory_frac` 是**实现量不是设定量**（`~ 种群` Spearman +0.944）
⇒ **不要按实现 `frugivory` 反调剂量，那是调结果不是调原因。**
**预注册**：报出两臂的总通量与 `frugivory_frac`；
**若臂间总通量差 > 1 个种子间 SD，归因判为多变量**，结论必须写明「配比 + 总通量」而非「配比」。

### 18.7 护栏与分析口径

`p` 臂报捕食者丢失数（**报出，不做事后筛**——事后筛正是 Stage 1 判不了的原因）；
`n` 臂按构造无捕食者。两类**不许池化**。
分析口径同 §17.6：先格均值 → 12 格配对符号秩 → 比值用 `√2·σ̂_W/√r`、`σ̂_W` 取 90% 卡方上界
→ 比值 <1 判 undecidable；逐种子全报，不做 Bonferroni；统计走 `scripts/exp_stats.py`。

> **[2026-08-04 事后补订，`feasibility.md §16.2` 的代价换来的]**
> **`σ̂_W` 只在参与该对比的臂上池化，不跨异质臂。**
> 本节原文没写这一条，于是分析时把噪声池化到**四个臂**，而 `p` 臂的格内 SD 是
> `n` 臂的 **6–13 倍**（关掉捕食者 ⇒ 种群翻倍 ⇒ 世代钟慢 3–4 倍，格内方差本身
> 就是被处理改变的量）。后果：两个 **12/12 同向、p=0.00049、t=+8.5/+10.5** 的效应，
> 按四臂池化算出的比值只有 **0.49**，照字面要判 undecidable；只用 `n` 臂自估是
> **+2.70 / +3.22**。
> **判断异质性的现成指标就是各臂的格内 SD——差一个量级就不该池化。**
> 跨异质臂的比较另报，且**两种口径都列出来，不许挑一个用**。

**伪重复边界**：单地形 `ridge_wavenumber=1`，结论只推广到这条河系。
**新增边界**：`n` 臂是一个**没有捕食者的世界**，它买到的是干净的归因，
代价是结论不能直接外推到有捕食者的世界——**那正是 `p` 臂与 H2 存在的理由。**

## 19. 【R16】那个 50/50 双簇在 200+ 代上稳不稳（2026-08-05，run_id: `20260805-longrun`）

**用户已拍板执行（CONC=3 全量）。** 结论归 `multispecies_feasibility.md`；本节只放预注册判据，跑之前提交。

### 19.1 为什么是这一轮

§17/§18 确立了两件事：那个「中间被掏空的少数簇」**不是漂变+复发突变能造出来的**
（4 臂 × 4 个 `Ne` = 16 格全部 p<0.005），且**关掉捕食通道能把它放到 50/50**
（`R38n` 的 `split_score` **0.4501**、`low_mass` 0.4501，本纲领迄今最平衡的两簇。
⚠️ **原文写的 `split_score` 是修复前的 0.4423**——`88b8f44` 的平台修复把它更正为
0.4501，与 `low_mass` **相等**；两者相等不是巧合，是 §21.4b 那条恒等式
`split_score ≡ min(low_mass, 1 − low_mass)` 的必然，所以**它们不是两条证据**）。

**但 Stage 2 只跑了 42k 步，`n` 臂只走了 71–87 代。**
§18.5 明写「不能把 `R38n` 的 50/50 读成稳态」。R13 有 3 个自发丢失捕食者的 run
跑到 118–161 代仍在长（§17.3），但那只有 3 个、且是自发的（有 collider 风险）。

⇒ **本轮问的是稳定性，不是存在性。** 这是本纲领第一次有一个**已确立存在**的结构
可以去问它稳不稳，而不是再去找它存不存在。

### 19.2 设计

**2 臂 × 12 种子 × r=2 = 48 run × 100k 步 × 4 检查点。** 两臂只差 `diet_delta`：

| 臂 | `diet_delta` | 含义 |
| --- | --- | --- |
| `R38n` | **1.5** | 由构造无捕食（猎物需比攻击者食草 1.5 以上，而 `diet ∈ [0,1]`） |
| `R38p` | 0.15（默认） | 有捕食者 |

**世界（两臂共用，⚠️ 不是默认世界——9 项覆盖）**：
`fruit_energy=4.0  fruit_water_frac=0.40  plant_max=2.0  water_sea_dist=1
 grass_shade=1.3  forage_tradeoff=1.0  forage_curvature=1.0  eat_rate=0.5
 ridge_wavenumber=1  fruit_regrow_baseline=0.25  regrow_baseline=0.010`

### 19.3 【预先声明】世代钟不等长，一切按代不按步

42k 步时实测：`R38n` 走 **71–87 代**，`R38p` 走 **166–233 代**（关掉捕食者 ⇒ 种群翻倍
⇒ 世代钟慢 2–3 倍）。100k 步预计分别约 **170–210** 与 **400–560** 代。

**所有判据用世代加权的占空比**（`neutral_null.occupancy`，`mode="iso"`——
保序回归的权重总量等于真实跨代数，`clip` 口径会多造 2.24 倍权重，见 §18.4c）。
**逐臂报实测跨代数。不许按步比、不许把「n 臂跑的代少」当成它更稳的解释。**

### 19.4 判据（跑之前写死）

**H1（主判据，稳定性）**：`R38n` 里**末四分之一**（世代加权）`retained` 占空比 > 0.5
的 run 数，对**模拟**中性零假设检验（`neutral_null.report`，`Ne ∈ {105,340,600,2000}`，
估计量 `(1+k)/(reps+1)`，**同时报分辨率下限 `1/(reps+1)` 与零分布最大值**）。
- **拒绝** ⇒ 分裂在 ~200 代上仍非中性，`R38n` 的 50/50 不是 42k 步的暂态。
- **不拒绝** ⇒ **不等于「它塌了」**，只说明在 200 代上与中性分不开；须与 H2 合读。

**H2（稳定 vs 衰减）**：`R38n` 的占空比**末四分之一 − 首四分之一**，
先取格均值 → 12 格配对符号秩；噪声 `√2·σ̂_W/√r`，**σ̂_W 只在 `R38n` 上自估**。
- **≈0 且比值 ≥1** ⇒ 稳定；**显著为负** ⇒ 暂态。
- ⚠️ **比值 <1 一律判 undecidable**——**既不许读成「稳定」也不许读成「在衰减」**。
  「差不多没变」在一个功效不足的检验里，与「测不出来」是同一个数。

**H3（捕食通道，长时程复核）**：`R38n − R38p` 的末四分之一占空比差，12 格配对。
Stage 2 在 42k 步上是 **+0.6140**（12/12、p=0.00049、比值 +1.91）。**预测同号。**
- ⚠️ **噪声只在这两臂上池化**（`MEMORY.md [LEARN:stats]`）；若两臂格内 SD 差一个量级
  则**不池化**，两种口径都报、不许挑一个用。

**次判据（预先声明功效不足，失败一律读 undecidable）**：末四分之一的
`low_mass` / `split_score` / `mean_pref` 均值；检查点的逐箱摄入。

### 20.2 手术

`_assortative_mate` 现在按 `diet` 排序、按秩相邻配对。加一个**默认关**的旋钮：

```python
rank_key = diet if cfg.assortative_mating else jax.random.uniform(key, (n,))
if cfg.mate_forage_weight > 0.0 and cfg.assortative_mating:
    w = cfg.mate_forage_weight
    cls = (diet >= 0.5).astype(diet.dtype)
    rank_key = 2.0 * cls + (1.0 - w) * diet + w * forage_pref
```

**[对应] 三条实现约束，每条都有理由**：

1. **`w = 0` 走编译期 `if` 的旧路径**（`Config` 是编译期常量），与 `terrain.py` 的
   `if cfg.grass_shade > 0.0:` 同一模式。
   ⚠️ **这个 `if` 是承重的，不是装饰**——审查算出：float32 里 `2.0 + diet` 的 ULP 是
   `2⁻²²`，而 `diet ∈ [0.5,1)` 是 `2⁻²⁴`，**精度掉 2 bit**；两个 `diet` 相差 < 2.4e-7 的
   食肉者会**并列**，而 `jnp.argsort` 稳定（按 index 破并列）⇒ 给出与按 `diet` 排序
   **不同**的配对。约 1e-3/步，100k 步约 **100 次**。
   「序等价，所以只留数学不留 `if`」会让默认臂在长跑里悄悄偏离。
2. **`2.0 * cls` 的作用是「防止 `w` 变大后食肉者按 `pref` 混进食草者队列」，
   不是「让跨类配对结构性不可能」。** 跨类配对**仍然可能**：排序把两类分开之后，
   `swap = arange(n) ^ 1` 在边界仍会成对（食草 wanter 数为奇数时秩 `H−1` 与 `H` 配上），
   泄漏是 **0 或 1 对（期望 0.5 对/步）——与今天按 `diet` 排序完全相同**。
   结论「至少和现状一样强」成立，**但初版写的理由是错的**，这里改对。
3. **新参数加在签名末尾并带默认值**——`_assortative_mate` 有 **3 个调用点**，
   其中 `tests/test_kernel.py:1137,1141` 按位置传 4 参，改签名会打断 `--full`。

### 20.3 【预先声明】旋钮在 `w≈0.3` 就饱和，剂量点取 0.05–0.30

| `w` | 配偶间平均 \|Δpref\| | 跨簇配对比例 |
| --- | --- | --- |
| 0.00 | 0.3133 | **0.5001（= 随机）** |
| 0.10 | 0.1844 | 0.2572 |
| **0.20** | 0.0723 | **0.0419** |
| 0.30 | 0.0488 | 0.0021 |
| 1.00 | 0.0005 | 0.0008 |

**`w` 控制的是 `diet` 散布（0.035）与 `pref` 散布（0.3）的尺度比**，所以饱和得很快。

## 22. 【R19】隔离能不能自发演化（2026-08-05，**实现待 R18 跑完**，用户已批准作废种群）

### 22.1 问题

R17 只能说「**若隔离存在，则**两簇的全基因组分化高 47.8%」——`mate_forage_weight`
是我们拧上去的常量。R19 问的是**它会不会自己涨上来**。

### 22.2 ⚠️ 先说风险：这是一个**修饰基因座**，而本项目已经在同类问题上判过一次负

`docs/mutation_sigma_heritable.md`：把突变率做成可遗传基因（**同样是修饰基因座**），
6 种子实测**落「平凡」类负结果**——「修饰基因座机制存在可跑但**二阶效应测不出**，
要看需换尺度/更持久选择压」。

**修饰基因座的选择是二阶的**：它不直接影响携带者的存活或产仔数，只影响后代的**基因组合方式**。
所以本轮**先验上就有很大概率欠功效**。

**与那次的两个关键差别（也是这次值得再试的理由）**：
1. **那次没有实测的选择压**（静态地形、`Ne~2000`、无明确的适应度谷）；
   **这次有**——`feasibility.md` §21 实测中间带的实现适应度是 **−0.4194**，
   两端 +0.049/+0.015，**46/47 同向、p≈7e-14、dz≈−2.15**。
   这正是 Dieckmann & Doebeli (1999) 说的、同型交配会被选择出来的条件。
2. **那次的效应量无先验**；这次 R17 已量出隔离的**收益**（全基因组分化 +47.8%）
   与**代价**（种群 −5.6%）。

⇒ **本轮的阴性结果是有信息的**（「有明确选择压时修饰基因座仍然涨不起来」），
但**必须在跑之前就承认它很可能阴性**，不能事后当作发现。

### 22.3 手术

新增性状基因位（`trait_dim` 8 → 9、`genome_size` 1386 → **1387**）：

```python
def mate_forage_of(genome, cfg):
    # **单边映射**，与 escape/armor/spike 同模式（"一次性投资，买或不买"）：
    # gene = 0 ⇒ w = 0 ⇒ **默认逐位等于旧行为**。
    return jnp.clip(jax.nn.sigmoid(genome[:, cfg.mate_forage_index]) - 0.5, 0.0, None)
```

配对时用**双亲的均值**（同型交配是一个双向的交互，不能只看一方）。

⚠️ **代价，用户已批准**：`genome_size` 变 ⇒ **作废所有已演化种群**；
`golden.json` 必须 `--bless` 重录（先例：`trait_defense_landing.md` 的 `trait_dim` 5→7）。

### 22.3b 【实现偏离，写于跑之前】「双亲均值」不可实现，改用个体自己的 `w`

§22.3 写的是「配对时用**双亲的均值**」。**落地时发现它在本架构下无法实现**，
这里如实记下偏离与理由——**跑之前写，不是事后解释**。

**为什么不行**：`_assortative_mate` 的 `rank_key` 是**排序键**，
排序**决定**谁和谁配对；而「双亲均值」需要先知道配对结果。**循环依赖。**
（两轮迭代——先按个体 `w` 排一次得到初步配对、再用双亲均值重排——不收敛，
且第二轮的配对会再次改变均值。）

**改成什么**：`rank_key` 用**每个个体自己的 `w`**：

```python
w = mate_forage_of(genome, cfg)        # [n]，逐个体
rank_key = 2.0 * cls + (1.0 - w) * diet + w * forage
```

**为什么这仍然是双向的**（这才是 §22.3 想要「双亲均值」的原因）：
**两个个体能否排到相邻，取决于两者的键**。一个 `w=0` 的个体按 `diet` 排队、
一个 `w=0.5` 的个体按 `forage_pref` 排队——**它们被推开，正是同型交配的机制本身**。
所以双向性由「双方都参与排序」保证，不需要显式取均值。

**唯一的语义差别**：双亲均值会让「一强一弱」的配对按中间强度处理，
而现在是「各按各的强度排队」。前者更像一个协商模型，后者更像一个**偏好模型**——
后者在生物学上并不更差（觅食生境选择本来就是个体各自做的），
但**它不是 §22.3 承诺的那个模型**，所以记在这里。

### 22.4 判据（跑之前写死）

**⚠️ 读数必须是「平均基因」，不是「平均 `w`」。**
`w = clip(sigmoid(g) − 0.5, 0, None)` 是**单边**的 ⇒ 纯漂变下**一半的位移不可见**，
`mean w` 会**由构造从 0 往上漂**。那会是一个 by-construction 的假阳性。
**`mean gene` 在中性下是严格的鞅**（`neutral_null.py` 已验证并有单元测试）。

**H1（主）**：末检查点的 **`mean mate_forage_gene`** vs **模拟中性零假设**
（复用 `neutral_null.sim_genes`，`Ne ∈ {105,340,600,2000}`，
估计量 `(1+k)/(reps+1)`，同时报分辨率下限与零分布最大值）。
预测：**若隔离被选择，则显著为正。**

**H2（生态对照臂）**：`forage_tradeoff=0` 的臂——**没有权衡就没有谷**，
隔离没有理由被选择。**若两臂都涨，那涨的不是隔离而是别的东西。**

**次判据**（预声明功效不足）：`ld_mean_abs_d`（R17 的主判据）、`low_mass`、`split_score`、
以及**实测的 `mean w`**（只作描述，**不当判据**，理由见上）。

**MDE 必须在看到主臂之前算死**（§20.4b 的纪律）：用 H2 对照臂或 R18 的数据自估 `σ̂_W`，
并写出「预测效应 ÷ MDE」。**若比值 <1，本轮从设计上就判不了，届时不许当作阴性发现。**

### 22.4b 【MDE 与选择压，跑之前算死，零 GPU】选择压是**高度时变**的——这改变了设计

§22.4 要求「MDE 必须在看到主臂之前算死」。算完之后发现的东西比一个 MDE 数字重要得多。

#### ① MDE：`mean gene` 要涨到 **0.176**

用 `neutral_null` 的同一套演化规则（Wright-Fisher 重抽 + `N(0, 0.02)` 突变，
初始 `N(0, 0.4)`）向量化模拟「24 个 run 的 `mean gene` 之均值」的零分布：

| 代数 | Ne=105 | Ne=340 | Ne=600 | Ne=2000 |
| --- | --- | --- | --- | --- |
| 375 | 0.1518 | 0.1379 | 0.1079 | 0.0677 |
| 669 | **0.1761** | 0.1300 | 0.1663 | 0.0787 |

（每格 95 分位，60 次重抽 × 24 run。）**取最宽的 ⇒ MDE = 0.176**，
换算成表型 `w = sigmoid(g) − 0.5` 是 **0.044**——只有 R17 那个拧上去的常量（0.30）的 **1/7**。
**MDE 本身是宽松的。**

#### ② 但选择压掉了 **26,075 倍**——而且是在分裂完成的那一刻掉的

同型交配的收益来自**让后代避开中间型**。中间型的实现适应度劣势 §21 已实测
（`s_mid = 0.4194`，46/47 同向、p≈7e-14）。所以每代选择系数的**上界**是
`p_mid × s_mid`，其中 `p_mid` 是中间带 [0.35, 0.65] 的质量占比。
在 R18-B 的 24 个 run 上实测：

| | `p_mid` | 选择系数上界 |
| --- | --- | --- |
| 最早 20 个检查点（分裂尚未完成） | **0.7425** | **0.311/代** |
| 末四分之一（分裂已完成 500+ 代） | **0.00003** | **0.000012/代** |

**⇒ 分裂一旦完成，中间型就几乎不存在（0.003%），于是「避开中间型」这件事
不再有任何收益可言。** 这不是修饰基因座的二阶性问题（§22.2 说的那个），
而是一个更基本的问题：**被同型交配保护的那个损失，已经没有了。**

#### ③ 对设计的三个后果（**跑之前写死**）

1. **R19 的成败取决于最初约 63 代**（分裂形成期），不是后面的几百代。
   `feasibility.md` §24.6 实测双簇形成于头 13 代、谷在 gen 117 后彻底见底。
   **⇒ 跑 800k 步（R18-B 的规格）是浪费**：99% 的算力花在选择压已经归零的时段上。
2. **可证伪的预测**：若 R19 阳性，`mean gene` 的涨幅应**集中在早期**，
   而非全程线性累积。**这是一个非平凡的预测**——若实测涨幅均匀分布在全程，
   那涨的多半不是隔离而是别的东西（H2 对照臂正是为此设的）。
3. **⚠️ 「预测效应 ÷ MDE」在晚期远 <1**（0.000012×代数 vs 0.176），
   **按 §22.4 的字面，用 R18-B 那种长跑设计本轮从设计上就判不了。**
   早期那段（选择系数上界 0.311/代 × ~63 代）才是唯一有功效的窗口，
   但它的实际功效取决于 `w` 的频率依赖收益，**本节没有把它算死**——
   这是一个**尚未关闭的功效缺口**，跑之前必须由用户拍板是否接受。

#### ④ 这一节改变了什么

§22 原本假设「跑得够长就能看到隔离涨起来」。实测说**恰恰相反**：
**跑得越长，后面越是纯噪声**。R19 该问的是
「**在分裂正在形成的那 63 代里，隔离能不能搭上车**」，
而不是「500 代之后隔离长起来了没有」。

### 22.4c 【入侵障碍，跑之前算死，零 GPU】小 `w` 的选择是**负的**——这才是 R19 的真障碍

§22.4b 算出「选择压在分裂完成后掉 26000 倍」。但还有一个更早、更硬的障碍，
它在**分裂正在形成时**就已经存在——**而 §22.2 完全没有预见到它**。

#### 问题：一个孤立的 `w>0` 个体，找得到同类吗

`rank_key = 2·cls + (1−w)·diet + w·forage`。在一个 **`w` 普遍为 0** 的种群里，
**队列是按 `diet` 排的**，而食草者内部 `diet` 只散布 **0.035**、且与 `forage_pref`
**不相关**。所以一个 `w>0` 的个体虽然按自己的 `forage` 重新排了位，
**它的新邻居仍然是 `forage` 随机的个体**——它换了位置，却没有换到同类身边。

#### 实测（复刻 `_assortative_mate` 的排序-相邻配对，用本世界实测的分布参数）

`N=4000`、`diet~N(0.20, 0.035)`、`forage` 双峰 0.151/0.720（§20.3 与
`forage_visualization.md` 的实测簇位）、入侵者占 2%、60 次重复：

| 入侵者的 `w` | **孤立入侵者的配偶相似度收益**（已扣 `w=0` 基线） | 全体都采用时的收益 |
| --- | --- | --- |
| 0.05 | **−0.0088 ± 0.0037**（**显著为负**） | 0.0417 |
| 0.10 | **−0.0003 ± 0.0032**（≈ 0） | 0.1230 |
| 0.20 | +0.0580 ± 0.0034 | 0.2310 |
| 0.30 | +0.1029 ± 0.0031 | 0.2574 |
| 0.50 | +0.1320 ± 0.0028 | 0.2768 |

**⇒ 三条结论：**

1. **突变的第一步不但没有收益，反而有害**（`w=0.05` 时收益 −0.0088，2.4 个 SE）。
   它打乱了自己本来按 `diet` 排好的匹配，却换不到 `forage` 上的同类。
2. **要到 `w≈0.2` 才有正收益**，而 `w=0.2` 需要 `gene ≈ 0.81`；
   基因每代只漂 `σ=0.02`，**在到达那里之前选择一直在把它往回推**。
3. **正频率依赖**：`w=0.3` 的孤立入侵者只拿到全体采用时收益的 **40%**。
   这个基因**要先有频率才拿得到收益**——经典的入侵障碍。

#### 把「配偶相似度」翻译成实际选择系数——阈值在 `w ≈ 0.2`

配偶相似度只是中间量。真正的选择系数要经过「后代落进中间带的概率 × `s_mid`」。
用同一个模拟（后代 `forage ≈ 双亲均值 + N(0, 0.02)`）算：

| 入侵者 `w` | 后代落中间带的 P | 常驻者 P | **选择系数 `s_w`** |
| --- | --- | --- | --- |
| 0.02（**突变第一步**） | 0.4813 | 0.4832 | **+0.00029** |
| 0.05 | 0.4873 | 0.4805 | **−0.00335** |
| 0.10 | 0.4790 | 0.4814 | **+0.00049** |
| **0.20** | 0.3701 | 0.4823 | **+0.04653** |
| 0.30 | 0.2895 | 0.4797 | +0.07928 |

**⇒ `w ≤ 0.10` 的选择系数是 −0.003 ~ +0.0005（≈0），而 `w = 0.20` 跳到 +0.047——
100 倍。存在一个明确的阈值：`w ≈ 0.2`，即 `gene ≈ 0.847`。**

#### ⚠️ 【自我更正】阈值 ≠ 不可逾越——正收益区从第 0 代起就有居民

**本节初稿据此写「预测 R19 阴性，因为第一步迈不出去」。那说过头了。**
基因初始化是 `N(0, genome_init_scale=0.4)`，而阈值是 0.847 = **2.1 个初始 SD**：

| 代数 | 个体 `gene` 的 SD | **`gene > 0.847` 的个体占比** |
| --- | --- | --- |
| 0（初始） | 0.400 | **1.7%** |
| 63 | 0.435 | 3.5% |
| 375 | 0.558 | 6.1% |
| 669 | 0.667 | **10.1%** |

（个体散布主要由初始分布决定——突变 `σ=0.02` 累积得很慢。）

**⇒ 入侵障碍不是「无人能到」，而是「到了的人能不能把整个种群拉过去」。**
这是一个**阈值突破 / 双稳态**问题，不是不可能性论证。**而这正是要实测的。**

#### 这对 R19 意味着什么

**[提案，非结论] 预测：R19 的结果取决于阈值之上那 1.7–10% 的个体能否点起正反馈**
（它们互相配对 ⇒ 局部高频 ⇒ 收益更高 ⇒ 更多后代在阈值之上）。
这是一个**机制性的、可证伪的**预测：

- 若 `mean gene` 不涨、且**阈值之上的占比也不涨** ⇒ 正反馈没点着，阈值挡住了；
- 若 `mean gene` 不涨、但**阈值之上的占比在涨** ⇒ 正反馈正在积累，**只是还没到临界**
  ——那意味着更长的时程会翻正，是一个明确的下一轮设计；
- **若 `mean gene` 显著为负 ⇒ 选择在主动压制**（`w=0.05` 那个 −0.00335 的区间在起作用）；
- 若涨到 MDE 以上 ⇒ **阈值被突破了**，那才是「隔离自发演化」的正面证据。

**⇒ 判决必须加一个读数：`gene > 0.847` 的个体占比**（不只是 `mean gene`）。
`mean gene` 会把「10% 的个体冲上去、90% 不动」平均成「几乎没动」，
而那恰恰是正反馈点火的样子。**这个读数零成本**——`metrics` 已经有整列基因。

**⇒ 建议 R19 增设一个臂来直接检验这个机制**（**需要用户拍板，本节不自行改判据**）：
`gene` 初始化在 **0.81 附近**（`w≈0.2`，正收益区）而非 0 的一臂——
- 若它**能维持**而 `gene=0` 的一臂涨不起来 ⇒ **入侵障碍被证实**，
  R19 的答案就成了「**隔离演化不出来不是因为没用，是因为第一步迈不出去**」；
- 若它也塌回 0 ⇒ 说明连维持都做不到，那 §22.2 的「二阶效应太弱」才是主因。

**这一臂零额外成本**（同一套代码，只改初始基因），却把一个笼统的阴性
变成一个**有机制的判决**。

### 22.4d 【跑前探针，2026-08-06】数据管线差点漏了，而对照臂暴露出一个**非隔离的机制**

#### ① 数据管线：`trajectory.py` 根本不记 `mate_forage_gene`（已修）

`_hist_fn` 一直只算 `forage_pref` 的直方图。**若照原样开跑，16 小时之后不会有
任何 H1 需要的数据。** 已加三个读数（append，旧脚本按 key 取，不受影响）：
`mf_mean`（H1 主读数，**原始基因**）、`mf_above`（`gene > 0.847` 的占比，§22.4c
要求的那个）、`mf_hist`（20 箱，值域 [−3, 3]）。
⚠️ **两处 `traj.append` 都要接**——第二处正是**末检查点**，而 H1 的主判据就是它，
初版只接了第一处，验证时才发现。

#### ② 跑前探针（3000 步 ≈ 14–17 代、单 run、无重复——**不是判决**）

| `forage_tradeoff` | 首 `mf_mean` | 末 `mf_mean` | 末 `mf_above` | 末代数 |
| --- | --- | --- | --- | --- |
| **1.0**（主臂：有权衡 ⇒ 有中间型劣势 ⇒ 隔离有收益） | +0.0202 | **+0.6243** | 0.2773 | 17.3 |
| **0.0**（H2 对照：无权衡 ⇒ 无谷 ⇒ 隔离没理由被选择） | +0.0048 | **+0.2072** | 0.0177 | 13.8 |

**主臂是对照臂的 3 倍**，方向与 §22.4b「早期选择压 0.311/代」一致。
**但对照臂也涨了 +0.207，而它按设计不该涨**——14 代的中性零分布远窄于此
（375 代、Ne=105 时 `mean gene` 的 SD 才 0.098）。

#### ③ ⚠️ 这意味着有一个**非隔离的机制**在推高这个基因

**H2 对照臂的全部意义就是「若两臂都涨，涨的就不是隔离」。** 现在它涨了。
在跑正式实验之前必须知道那是什么。一个待查的候选（**[提案，非结论]**）：

> `rank_key = 2·cls + (1−w)·diet + w·forage`。当 `forage_tradeoff=0` 时 `forage_pref`
> 没有表型效应、纯中性漂变，但**它仍然存在于排序键里**。于是 `w` 高的个体都按
> 同一个（中性的）`forage` 轴排队——**它们因此互相靠近，也就更容易互相配对**。
> 若 `w` 与 `forage` 在基因组上偶然相关，这就是一个**与适应度无关的正反馈**：
> `w` 高的个体聚在一起 ⇒ 后代继承高 `w` ⇒ `w` 涨。**by-construction，不是选择。**

**⇒ R19 在跑之前需要第三个臂来隔离这个机制**（**需用户拍板，本节不自行改判据**）。
两个候选：
- **`assortative_mating=False`**：完全关掉排序配对，`w` 无从表达 ⇒ 若仍涨，
  那连排序都不需要，问题在别处；
- **把 `rank_key` 里的 `forage` 换成一个每步重抽的独立随机数**：保留「按 `w` 强度
  改变排队依据」这件事，但**切断它与任何可遗传量的关联** ⇒ 若这一臂不涨而
  `forage_tradeoff=0` 臂涨，上面那个正反馈假说就被证实。

**在这个机制查清之前，R19 的任何阳性结果都无法归因于隔离。**

### 22.4e 【三轮探针，跑之前】排序键有两个 by-construction 偏差，都修掉了；而第三个不是偏差

§22.4d 的四臂探针（20k 步 ≈ 40–48 代、4 seed/臂）跑了三个版本，每版只改排序键：

| 臂 | 原版 | 秩变换 | **秩 + 方差归一（最终）** |
| --- | --- | --- | --- |
| **A** 主臂（有谷、真实轴） | +0.679 | +0.004 | **+0.597** |
| **B** 无谷、真实轴 | +0.437 | −0.257 | **+0.396** |
| **C** 随机轴（切断遗传关联） | +0.267 | −0.250 | **−0.007** |
| **D** 关掉同型交配 | −0.065 | −0.015 | **−0.072** |

（判定门槛 MDE = 0.176。）

#### 偏差一：`w` 越大，个体被甩得越远（原版）

`rank_key = (1−w)·diet + w·axis`，而食草者内部 `diet` 只散布 **0.035**、`axis` 散布 0.3–1.0。
**⇒ `w` 高的个体被甩到队列两端，而两端只有其他高 `w` 个体，它们因此互相配对、
后代继承高 `w`。** 实测：即使把 `axis` 换成**纯随机数**（C 臂），`mean gene` 仍涨
**+0.267**（超过 MDE）。**修法**：两个轴都做秩变换，压成 [0,1] 均匀。

#### 偏差二：线性混合的方差**本身就随 `w` 变**（秩变换版）

秩变换把正向假信号消掉了（A 从 +0.679 掉到 +0.004），**却翻出一个反向的**（B/C ≈ −0.25）。
原因是个数学必然：两个**独立**轴线性混合时

    Var((1−w)·X + w·Y) = ((1−w)² + w²)·Var

它在 `w=0` 时是 1、`w=0.5` 时只有 **0.5** ⇒ **高 `w` 的个体反而挤在队列中间**，
换成低 `w` 的落在两端互相配对，把 `w` 压下去。
**「线性混合两个独立轴」这个形式做不到方差对 `w` 恒定**——必须再除以
`sqrt((1−w)² + w²)`。除完之后 `w=0` 仍恰是 `rank(diet)`、`w=1` 仍恰是 `rank(axis)`，
语义不变。**⇒ C 与 D 回到 −0.007 / −0.072，都低于门槛，排序机制不再造假信号。**

> ⚠️⚠️ **【撤回，2026-08-11 复核 fable5 抓到】上面这句跑前验收是错的，
> 而且错在方法而不是数字。** 那个 −0.007 出自 **4 个 run**，逐 run 是
> +0.404 / +0.118 / −0.062 / −0.488、**SD 0.373、SE 0.187**——
> **对 +0.22 这个量级的偏差毫无检出功效（z≈1.2）。它不是「修好了」，
> 是「什么都看不见」。**
> 正式实验（96 run）显示最终版的键在**同一尺度**（gen40）上仍偏 **+0.216**、
> 11/12 同向、p=0.0049，与原版探针的 +0.267 同量级——**三轮修复没有压住任何东西**。
> **教训：拿一个欠功效的探针宣布「偏差已修复」，比不验收更糟——
> 它给了一个假的安全感，而正式实验因此白跑了 8.5 小时。**
> 详见 `feasibility.md` §25.2。

#### 但 B 仍涨 +0.396——**那不是偏差，是真机制，而且它推翻了原来的对照设计**

B 与 C 的唯一差别是「轴是**可遗传的** `forage_pref`」而非随机数。
B 臂 `forage_tradeoff=0` ⇒ `forage_pref` 无表型效应、纯中性漂变，
**所以 B 的涨幅不可能来自适应度收益**。它来自：
**按一条可遗传的轴配对，会让同型交配基因与那条轴形成关联而搭车扩散**——
这正是 Dieckmann & Doebeli 模型的核心机制之一，**不是 bug**。

**⇒ 原来的判据设计错了。** §22.4 把 B（`forage_tradeoff=0`）当 H2 对照，
指望它隔离出「适应度收益」——**它隔离不出来**，因为搭车扩散在 B 里照样发生。
能隔离出来的是 **C（随机轴）**：它切断了轴的可遗传性，因此同时关掉了搭车与收益。

**修改后的判据（跑之前写死）**：

| 量 | 含义 |
| --- | --- |
| **C** | **真正的零点**（排序机制在，但轴不可遗传 ⇒ 既无搭车也无收益） |
| **A − C** | 隔离机制的**总效应**（搭车 + 收益）。探针上 **+0.604** |
| **A − B** | **适应度收益的净效应**（两臂都有搭车，只差有没有谷）。探针上 **+0.202** |
| **B − C** | **搭车扩散**单独的贡献。探针上 **+0.403** |
| **D** | 阴性对照，`w` 无从表达 ⇒ 应 ≈ 0 |

**⇒ 四个臂各回答一个问题，全部要跑。** 判决必须把「总效应」与「收益的净效应」
分开报——**只报 A−C 会把搭车说成隔离被选择**。

### 22.5 边界

- 跑在 **R38 世界**（`forage_tradeoff=1.0` 等 9 项覆盖 + `diet_delta=1.5` 由构造无捕食）。
- **不外推到有捕食者的世界 / 别的地形 / 默认世界。**
- **正结论也只能说「在这个已经有深谷的世界里，隔离基因会涨」**，
  不能说「物种形成在本沙盒中自发涌现」——那还需要生殖隔离到位后的**不可杂交性**，本轮不测。
- 落地后第一件事是 **`jax.make_jaxpr` 指纹验证**（不是「跑两次 diff 输出」——
  同一份代码跑两次有 47 个字段不同）。⚠️ 但这次 `genome_size` 变了，
  **默认臂的指纹本来就会变**——所以验的是「`mate_forage_gene = 0` 时行为与旧版统计等价」，
  用 golden 重录前后的 10 项指标带做验收，不是指纹。

## 23. 【R18-B】那个漂移**停在哪**（2026-08-06，用户已拍板全卡 CONC=8，run_id: `20260806-gen700`）

**跑之前提交。** 结论归 `multispecies_feasibility.md`。

### 23.1 为什么是这一轮

R18 判决（`feasibility.md` §22）自己留下了唯一一个未答问题：
**漂移在减速，但 375 代内没停。** 而 §22.6 的补记把这句话削弱了一层——
末段增量 +0.00999、**比值只有 +1.05**，**涨幅已经逼近本实验的分辨率下限**。

⇒ **这一轮的价值恰恰在于：把漂移推到分辨率之下，然后用等价性检验确认它真的停了**
（而不是「没检出」）。若它不停，那同样是结论，而且是更重的那个——
说明这不是趋向不对称平衡，是**正走向固定**。

### 23.2 设计

与 R18 **完全同一个世界、同一个臂**（9 项覆盖 + `diet_delta=1.5`），只加步数：

| | R18 | **R18-B** |
| --- | --- | --- |
| 步数 | 350k | **800k** |
| 实测/预计跨代数 | 375 [345, 431] | **预计 690–730（实测为准）** |
| run | 12 种子 × r=2 = 24 | 同 |
| 并发 | CONC=8 | 同 |
| 时长 | 约 7 小时 | **约 16 小时** |

**[对应] 为什么必须从头重跑**：`trajectory.py` 没有 resume，
`main(steps, seed, overrides, as_json, checkpoints)` 不保存 state，
R18 的 24 个 run 也没有留下可续的检查点。前 350k 步是重复劳动，但没有别的路。

**为什么是 800k**：实测世代钟持续变慢——682.6 → 900.8 → 1112.2 → **1242.9 步/代**
（R18 的四个四分位）。按末段 1243 步/代外推，700 代需 754k 步，
而**世代钟还会继续变慢，所以那是下界**，取 800k 留余量。
⚠️ **实测跨代数是读数不是假设**（§21.2），判决按实际达到的代数写，
**不许写成「700 代」**。

### 23.3 【预先算死】等价性阈值 δ 与可证伪的预测

**δ 用 R18 的 24 个同配置 run 直接自估**（同世界、同臂、同段长）：

- 末段增量的 `σ̂_W = 0.00953` ⇒ **配对差噪声 = 0.00953**
- **⇒ δ = 0.0095**（`CLAUDE.md`：护栏容差按 `√2·σ̂_W` 定，**不靠直觉**）
- 判决时 δ **用本轮自估的值**，上面这个是预估。

**[提案，非结论] 可证伪的预测**：若几何衰减以 R18 实测的公比 **r=0.575** 继续
（段长 62.8 代）：

| 目标 | `low_mass` | 末段增量 | 与 δ=0.0095 比 |
| --- | --- | --- | --- |
| 600 代 | ≈ 0.5963 | **+0.00105** | **远低于 δ** |
| 700 代 | ≈ 0.5971 | **+0.00044** | **远低于 δ（21 倍）** |

> **⇒ 若几何衰减成立，本轮对「停了」有充足功效**：预测的末段增量比 δ 小 21 倍。
> ⚠️ **这句功效结论本身建立在几何外推成立之上，而那正是 H2 要检验的东西**
> （复核 fable5 指出，2026-08-06）。**若几何衰减不成立，H1 的实际功效未知**
> ——判决时若 H1 落进 undecidable，不许说「本轮功效充足所以是真的停了」。
> **反过来**，若实测末段增量仍 ≥ δ，那就**推翻几何衰减**，
> 说明漂移比 R18 外推的更持久——**那才是本轮真正值钱的结果**。

### 23.4 判据（跑之前写死）

**⚠️ 关键口径：按固定段长（**约 63 代**，与 R18 的段长一致）切，不按固定段数。**
R18 用 6 段 × 62.8 代；R18-B 若同样切 6 段则段长变成 ~117 代，
**噪声与效应都不可比**。判决时段数由 `round(实测跨代数 / 62.8)` 决定。

**H1（主）：漂移停了没有——等价性检验。**
末段增量（最后一段 − 倒数第二段）先格均值 → 12 格 → `bootstrap_ci`：

- **95%CI 完全落在 `[−δ, +δ]` 内 ⇒ 停了**（这是等价性，不是「没检出」）；
- **95%CI 完全落在 `[+δ, ∞)` 内 ⇒ 没停**，且推翻几何衰减；
- **否则 ⇒ undecidable**，一并报比值与 `√2·σ̂_W`。

**H2：几何外推验证。** 末段 `low_mass` 是否落在 **[0.585, 0.610]**（R18 外推 0.597 ± δ）。
⚠️ **本条预先声明功效不足**：预测差（0.597 − 0.584 = 0.013）与 `low_mass` 的
配对差噪声（R18 实测 0.0113）同量级 ⇒ **比值约 1.1，刚过闸**，
落在区间内**不能**当成「外推被证实」，只能说「不矛盾」。

**H3：双簇还在不在。** 「两峰都找到的占比」与「谷未见底度」（§21.4b 的第二个轴）。

**⚠️ 口径改了（2026-08-06，复核 fable5 指出，R18-B 跑到 0/24 时定，不涉及本轮任何数据）：
这两条要在【全部检查点】上扫，不是只在早窗+末四分之一上。**
R18 的教训：那两个窗只覆盖 **41.7%** 的检查点，于是「窗内全饱和」被写成了
「全程都在」，而全量上有 275 个检查点无双峰、1248 个谷未见底
（**全部在 gen 63 之前** ⇒ 双簇是**形成于**头 63 代，不是全程都在）。
判决要报：**失败计数、占比、最晚出现的世代、`gap` 最小值**。

- **只在早期失败、`gen > 某界` 后全干净 ⇒ 双簇形成于该界，此后未并合**
  （定性，非检验，**不许写成「经检验稳定」**）；
- **若在晚期出现失败 ⇒ 这是本轮最重要的发现**，说明簇在更长时程上开始并合，
  必须单独成节报，并给出**第一次晚期脱离的世代**。

**H3b：少数簇质量 `min(low_mass, 1 − low_mass)`（新增一等读数）。**
`gap ≡ 1` 时它**就是**分裂强度本身，也是 §21.1 直接要的那个量。
R18 实测它从峰值 0.4803 跌到 0.4158（**−13.4%**），末段增量 −0.00999、3/12、p=0.00684。
本轮同样做**等价性检验**，阈值用**本轮自估**的配对差噪声（R18 上是 0.00953，与
`low_mass` 的末段增量同一个量的符号相反，所以 δ 相同）：
- CI ⊂ `[−δ, +δ]` ⇒ **收缩降到 δ 以下**；CI ⊂ `(−∞, −δ]` ⇒ **仍在快速缩**；否则 undecidable。
  > ⚠️ **【更正，2026-08-06 复核】本条初版写的是「CI ⊂ [−δ,+δ] ⇒ 少数簇不再缩」，
  > 而「不再缩」是一个无限定的零断言**——判决照抄它，写出了与自己报的 CI（不含 0）
  > 相矛盾的句子。**等价性判定给的是上界，不是零。** 措辞已改成「降到 δ 以下」。
- **判决必须同时报多数侧与少数侧**——只报 `low_mass` 上升会让结论听起来比实际乐观。

**H4：中性对照。** 末四分之一的 `retained` 计数 vs 模拟中性零假设
（`Ne ∈ {105,340,600,2000}`、`reps=200`、`(1+k)/(reps+1)`），同时报分辨率下限
与零分布最大值。R18 上是 24/24 vs 最大 5/5/5/1。

### 23.4b 【勘误，写于只看到 8/24 时】H3 缺一条「暂态 vs 并合」的判据，**不改任何阈值**

第一批 8 个 run 跑完做管路空跑时，H3 的全检查点扫描立刻触发了 §23.4 里
「**若在晚期出现失败 ⇒ 这是本轮最重要的发现**」那一条：

    R38n_s1_r2   gen 116.07  gap=0.000332   ← 谷未见底
    R38n_s1_r2   gen 116.39  gap=0.002354
    R38n_s1_r2   gen 116.87  gap=0.003712
    R38n_s1_r2   gen 117.17  gap=0.000338
（R18 的最晚失败是 gen 63，所以 gen 117 确实"晚"。）

**但它是一次暂态，不是并合**——前一个检查点 `gap=1.000000`、后一个也是
`gap=1.000000`，`low_mass` 全程在 0.504–0.522 之间几乎不动，
**此后 2871 个检查点全部恢复 `gap=1`，到 gen 658 再无失败**。

⇒ **§23.4 的缺口**：它写了「晚期失败 = 最重要的发现」，**却没说怎么区分
「一次 1 代的瞬时扰动」和「双簇真的开始并合」**。照字面执行会把前者报成后者。

**补上判据**：晚期失败必须先分类，报三个数——

> ⚠️ **【更正，2026-08-06 复核】本节初版自称「不改任何阈值」，那是错的**：
> 实现里的 `gen > 100` 就是随本勘误一同引入的**新阈值**（R18 的脚本根本没有
> 全检查点扫描）。**并且本条判据是 post-hoc 的**——被它裁决的 `R38n_s1_r2`
> gen 116–117 事件连同其后 540 代的完整恢复，**全部在写它时已经看到的那 8 个 run 里**，
> 所以决定性的「之后是否恢复」是在已知答案下选的。**「只看到 8/24」不构成辩解。**
> 支撑本条结论的是另外两件事（见 `feasibility.md` §24.6）：**样本外**（判据冻结后
> 16 个新 run 零新增晚期失败）与**阈值稳健**（gen 43.5–116.1 之间零失败，
> (44,116) 内任何阈值给同一组事件）。

| 问 | 怎么答 |
| --- | --- |
| 涉及几个 run | 1 个 ⇒ 更像个体级噪声；多个 run 同期失败 ⇒ 才像系统性 |
| 连续跨几代 | 本例 1.1 代 |
| **之后恢复了吗** | **这一条是决定性的**：其后全部 `gap=1` ⇒ **暂态**；其后仍有失败 ⇒ **并合** |

- **暂态** ⇒ 照常报计数与最晚世代，但**不许写成「双簇开始并合」**；
- **并合**（其后仍有失败）⇒ 才是 §23.4 说的那个「最重要的发现」，单独成节，
  并给出**第一次不再恢复的世代**。

判定已实现在 `explorations/20260806-r18b/analyze_r18b.py`（自动分类并打印三个数）。
