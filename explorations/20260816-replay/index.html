一群没人教过的生物，自己分成了两种吃法

Underworld 是一个 2D 人工生命沙盒。里面的生物没有被写死任何行为： 每一只带着一个可演化的小型神经网络，靠一圈视网膜感知世界，然后自己去活或者死。 下面这两件事不是设计出来的，是选择压力筛出来的。

看到的是什么

分化是真的，不是随机漂变
四个独立的中性零模型检验全部 p<0.005。分化在头 13 代内形成， 到第 669 代仍未合并回去。
两个生态型在空间上确实分开了
偏爱吃果子的个体里 77–85% 正站在长果子的地上； 偏爱吃草的只有 3–5%。这不是看图看出来的， 是逐帧算出来的（地图页上实时显示）。
加一种捕食者，吃果子的那一支就消失
同一个世界，只多了捕食者：果子专精那一簇从约 0.48 掉到 0.02–0.15，12 个随机种子全部同向。 三张不同地形上都成立。
而且这不是「压力大小」的问题，是「捕食者在不在」的问题
把捕食难度的门槛调高近五倍，只要捕食者还维持得住种群，压制程度就不变 （果侧始终 0.02–0.05）。门槛再高一点，捕食者自己饿死，吃果子的那一支立刻 整个回来。没有中间档。
诚实标注：「捕食者在不在」这个拆分是按结果分组的，只能说明两件事同时发生， 不能证明因果——真要证明，得从外部把捕食者数量钳死，而不是继续调难度参数。 另外临界点的位置分辨率只有 0.10 宽（0.70 和 0.80 之间没有采样点）， 而且「三张地形」里只有一张是真正的新河系，另一张其实是第一张的平移。 完整的统计口径、撤回记录和「这条结论不许可什么」写在 docs/ 里。

这些页面是什么

都是已经跑完的模拟的回放，不是实时演算——所以双击就能打开，不需要显卡， 也不需要起服务器。数据直接内嵌在页面里。

想看实时的

在仓库根目录跑下面这行，然后浏览器开 localhost:8000。 大约两三分钟就能看到族群分裂：右下角的直方图长出两个峰， 同时地图上会出现一团团橙色——那是吃果子的个体自己聚到了结果子的地方。

XLA_PYTHON_CLIENT_PREALLOCATE=false .venv/bin/python scripts/run_live.py --speed 50 \
  --set fruit_energy=4.0 --set fruit_water_frac=0.40 --set plant_max=2.0 \
  --set water_sea_dist=1 --set grass_shade=1.3 --set forage_tradeoff=1.0 \
  --set forage_curvature=1.0 --set eat_rate=0.5 --set ridge_wavenumber=1 \
  --set fruit_regrow_baseline=0.25 --set regrow_baseline=0.010 --set diet_delta=1.5
那一长串参数不是装饰。直接跑 run_live.py（默认世界） 是看不到分化的——这个分化是九项干预累积出来的结果，不是这个沙盒开箱即有的性质。 上面这些覆盖就是判决里那个世界的完整配置，一项不少。
想看捕食者把它压掉：把最后那个 --set diet_delta=1.5 删掉再跑一次。 那一项是「关掉捕食」的开关，去掉它捕食者就回来了，几分钟内橙色那一支会整个消失。

开头那个环境变量不能省：没有它 JAX 会先占掉显卡的 75%，下一个启动的进程就会撞上一个假的「显存不足」——实际峰值只有 918 MiB。 --speed 50 是每帧推进多少步（时间加速），调大更快但画面会跳。
