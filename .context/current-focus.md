## 非目标

- **不能说「物种形成涌现了」**，也**不能说「两个物种」**。
- **不能说「同型交配让分裂更稳」**——稳定性没测（`split_score`/`low_mass` 的判决是
  「读数失效 + 无差异」）。
- 不外推到**有捕食者的世界**（主臂 `diet_delta=1.5` 由构造无捕食）、
  **别的地形**（单地形伪重复）、**默认世界**（9 项非默认覆盖）。
- 引用 §20.3 的剂量表要说明**它是模型不是实测**（假定簇位 0.151/0.720，实测 0.031/0.798）。

## 纪律（每条都有实测代价）

- **饱和的读数不能当判据的分母**（`conventions.md` §11）。噪声估计前先查有没有顶格。
- **守卫的失败模式必须比它守的东西更吵**——从不报警的守卫比没有守卫更糟。
- **零假设优先用模拟，而且要模拟「你实际会算的那个数」**（过程层面的零假设 ≠ 估计量的）。
- **顶在地板上的 p 是分辨率耗尽**（n=12 的 0.00049、蒙特卡洛的 `1/(reps+1)`）。
- **读数要对着被测对象的真实分布定标**，不是值域中点。
- **跨回合引用一个臂之前，把它的 `overrides` 与 `Config()` 逐条 diff**——
  「基线臂」不等于「默认世界」，叫错会让结论反号。
- **限定词只在压缩转述层丢失**：改正文时同时改表头/图例/摘要。
- 判决派 `result-analyst`（fable5），计划派 `plan-critic`（fable5）**在动手之前**，
  实现完再派它复核。本 session 它们**每一次都改变了结论的措辞**。

## 环境上的坑

- **`merge.conflictstyle=zdiff3` 会让 `git stash pop` 静默丢工作**
  （这个 git 版本不认该值）。绕开：`git show 'stash@{0}:path' > path`。**建议 unset。**
- **「跑两次 diff 输出」不能当 bit-exact 验证**——同一份代码两次有 47 个字段不同。
  用 `jax.make_jaxpr` 的指纹，且脚本要 assert 拒绝空输出（第一版因报错而「通过」）。
- **sweep/分析在跑时源码树是冻结的**（它会陆续起新进程 `import underworld`）。
- 截图端口用 **8137** 不用 8000；点着色器的属性槽卡在 **8**（WebGL 1.0 下限）。
